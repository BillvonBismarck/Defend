## 已观察到的宿主限制

一次地图复验在初始化阶段原生退出（0xC0000005），没有生成本轮报告。Windows Application 事件 1000 记录故障模块为 NVIDIA `nvwgf2umx.dll`，版本 32.0.15.9191，应用为 `.cli/UrhoXRuntime.exe`；Report ID 为 `43fcaa01-d4ae-4f4f-b9c1-74caea799198`。这定位了崩溃发生的模块，尚不能单凭事件确定触发根因。后续同场景及两组压力场景复跑均正常退出。

验证脚本已修正为每次删除同名旧报告和截图，并同时检查新报告、进程退出、断言及真实运行快照，不会把遗留 PASS 报告当成本轮通过。未改用户显卡驱动或系统配置。

本轮证据属于本机短时自动验证，不代表手机长局、高波次真人验收；没有在本轮提交 Maker 远程构建。当前编辑器中原有调试实例需重新启动才能加载全部新文件。
