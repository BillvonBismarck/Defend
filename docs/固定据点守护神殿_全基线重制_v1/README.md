## 口径与已决事项

- 数值分三类标注：【实现】= 代码已有并可跑；【设计】= 本方案新增待实现；【缺口】= 基线已承认未完成。

- 几何定稿（紧凑型）：三角 10u（100 单位三角）/ 六边 6u（216）/ 十二边 4u（400，阶梯取整），**面积比 1 : 2.16 : 4.00**；走廊宽恒 2u、长 ∈ {2u, 3u, 4u}、轴只取 6 个奇数方向、只接边的中点。
- 环路判据：总转角 ±360° ＋ 三方向族长度平衡（异型房须对角成对）＋ 度数上限；3 房环只能全六边，6 房环可为「2 对角六边 + 4 三角」，全三角环要求环长为偶数且 ≥6。
