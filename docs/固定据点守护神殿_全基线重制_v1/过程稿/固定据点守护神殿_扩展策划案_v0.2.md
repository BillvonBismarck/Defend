### 1.2 原型现状（Maker 分享页，2026-10-08 核验）

**已实现（可作为扩展的正确落点）：**

- 战备 15 秒、自动攻击 + 无伤击退（空格）、三路入口与核心；
- **三种开局方案**：精准拦截（穿透火力）、范围清场（范围弹头）、控制妨防（减速弹头），均自带击退；
- 爆炸会伤害自己、核心和设施；墙柱阻挡伤害；
- W1–20 主流程、教学测试（5 波）、规则卡、上局战报、演出回看（开场/终局/收束）；
- 界面：角色/核心血条、波次/等级/资金/经验、入口提示、暂停。

**尚未实现（本文的扩展对象）：** 塔防建造与升级、大地图与外圈据点、终局考验波、大远征与房间限伤、速清奖励探索时间。

## 3. 扩展模块总览与优先级

```
战备/探索 15s（+速清奖励） → 8s 预警 → 波次进攻（基准攻击时间 B）
     ↑                                        │
     └──── 清波结算：速清奖励 +R（不结转） ◄───┘
                      │
        外圈探索 / 构筑升级 / 大地图推进（E2、E3）
                      │
        W20 清空 → 考验波（E4）→ 大远征（E5，含房间限伤）
```

| 模块 | 名称 | 一句话 | 依赖 | 建议顺序 |
| --- | --- | --- | --- | --- |
| E1 | 波次节奏与速清换探索 | 把战斗效率换成探索时间 | 无 | 1 |
| E2 | 复杂构筑防守系统 | 从三座塔到有组合、有分支的防线 | E1 | 2 |
| E3 | 大地图 | 主殿 + 三片主题区，用过不废 | E1、E2 | 3 |
| E4 | 终局考验波 | 最后追加一波，让全图参与 | E3 | 4 |
| E5 | 大远征与房间限伤 | 敌人绕全图一周，逐房间消耗 | E3、E4 | 4（与 E4 同批） |

设计原则：**先让时间与资源产生取舍（E1、E2），再让空间产生取舍（E3），最后用终局把前两者收束（E4、E5）。**

## 4. E1 波次节奏：基础间隔、基础攻击时间与速清换探索

### 4.1 问题

- v0.1 的战备固定 15 秒：无论打得好坏，探索窗口完全一样，**战斗效率无法转化为机会**；
- 杀太快的玩家面对空窗，杀太慢的玩家没有补偿，节奏是「平的」。

### 4.2 规则（原型建议）

| 时间量 | 定义 | 建议值 |
| --- | --- | --- |
| 基础间隔 B0 | 每波结束后的保底窗口（沿用 v0.1 战备 15 秒） | 15 秒【已确认】 |
| 基础攻击时间 B(w) | 本波«预期»战斗时长，写入波次配置 | 非 Boss 波 30s / Boss 波 45s |
| 实际战斗时间 T(w) | 从生成队列开始到清波判定成立的时长 | 运行时统计 |
| 速清奖励 R | R = clamp(B(w) − T(w), 0, R_max) | R_max = 15 秒 |
| 探索窗口 | B0 + R，设总上限 | ≤ 30 秒 |

- **提前开波保留**：玩家可随时提前进入下一波；已结算的 R 不会被没收，未用完的部分作废、**不结转**；
- **慢速不惩罚**：T(w) ≥ B(w) 时照常获得 B0；连续两波超时只给一句提示（“考虑先修复或布防”），不强制、不暗改数值；
- **清波判定沿用 v0.1**：生成队列执行完成 且 本波存活进攻怪为 0；有未结算的有害反应（如尸爆）时不算清波。

### 4.3 护栏（防止被玩坏）

| 风险 | 规则 |
| --- | --- |
| 刷时间 | 每波只结算一次；R_max 封顶；奖励时间不可跨波累积 |
| 提前清波套利 | 清波前必须完成生成；有害反应未结算不清波 |
| 压力被稀释 | B(w) 随波次不下降；R_max 不随波数增长 |
| 探索致核心被偷袭 | 预警仍保证 8 秒；探索窗口与预警解耦（沿用 v0.1） |
| 弱构筑被惩罚 | 保底 B0 不变；R 只奖励效率，不作为通行门槛 |

### 4.4 反馈

- 清波结算显示：`速清奖励 +12s（战斗 18s / 基准 30s）`；
- 倒计时区分「基础窗口」与「奖励窗口」两段视觉；
- 战报记录本波战斗时长、奖励秒数与探索去向（是否实际用于探图）。

### 4.5 验收

1. 正常构筑下，20 波中 ≥ 5 波可稳定拿到 ≥ 8 秒奖励；
2. 三路高压波「硬吃奖励」会掉核心耐久——机会成本可感知；
3. 弱构筑玩家仍获得 B0，不存在「不速清就无法完成探索」的死结。

## 5. E2 复杂有构筑的防守系统

### 5.1 问题与目标

现有四槽位、三类塔、两级升级只是占位。目标是让玩家在**选位—建什么—怎么升—怎么联动**四层都有真实决策，而不是「四座塔堆输出」。

### 5.2 四层结构（原型建议）

| 层 | 决策 | 方案 |
| --- | --- | --- |
| 布点层 | 在哪建 | 槽位分级：**主殿槽**（核心圈，保命区）/ **走廊槽**（拐点，拦截区）/ **据点槽**（远征防线）；槽位数量与位置绑定地图 |
| 设施层 | 建什么 | 四族：**输出**（速射、范围）/ **控制**（减速、击退）/ **阻挡**（路障、拒马）/ **支援**（维修、供能）；每族 ≥ 2 种 |
| 升级层 | 怎么升 | 每设施 2 次升级 + 二选一分支；分支不可逆；拆除返还累计支出 50%（沿用 v0.1） |
| 联携层 | 怎么组合 | 邻接 / 覆盖 / 状态三类联动；**只允许读取公共字段**（如「被减速的目标」），不做专用组合彩蛋（R1–R9） |

### 5.3 与三套开局方案对齐（原型已有）

| 开局方案 | 构筑倾向 | 主建设施 | 被克制情境 |
| --- | --- | --- | --- |
| 精准拦截 | 单体、穿透、击退 | 速射塔、拒马、击退台 | 密集群怪 |
| 范围清场 | AoE、清群、爆炸风险 | 范围塔、爆裂器 | 单体精英、近核爆炸 |
| 控制妨防 | 减速、阻断、换路 | 减速塔、路障、供能站 | 抗控与远程骚扰 |

### 5.4 经济（新增探索货币，【需确认】）

- **防守资金**：击杀 / 清波获得，用于基础设施（沿用 v0.1）；
- **探索货币（暂名「星砂」）**：只能通过据点与远征获得，用于高级设施与升级分支；每据点一次性、每局有上限，不能反复刷房套利（对应蓝本的「星币」分层）；
- 两种货币的存在意义：让「外出探索」与「守家防守」在资源上都有独立回报，而不是只能二选一。

### 5.5 公平性与反套路

- 单一最优解检查：范围塔对单体精英低效、速射塔对群怪低效（沿用 v0.1 定位），要求至少两套「非最优但可行」的组合；
- **不能封死路径**：设施 + 尸体 + 掉落物不得阻断 W/E/S 到核心的寻路（沿用 v0.1 验收项）；筑墙流派必须走寻路回退规则，不允许靠堵路让敌人卡死；
- 设施独立生命（建议 150，沿用）、可被摧毁、可被修复；设施与核心 `anchored=true`，不能被技能推动（R2）。

### 5.6 界面与可读性

- 建造预览：覆盖范围、阻挡位置、大致输出区间；升级对比页；
- 缺钱禁用并说明原因；被摧毁 / 断电 / 失控状态必须有独立图标与音效；
- 单局可见设施数量设上限（建议 ≤ 12 座，随章节解锁），避免屏幕与性能过载。

### 5.7 验收

1. 三套开局各自成立且战报可区分（不能只是皮肤差异）；
2. 至少两种「非最优但可行」的布防组合；
3. 建造 / 升级 / 拆除的扣款与返款只发生一次（沿用 v0.1）。

## 6. E3 大地图

### 6.1 现状与目标

现状：主殿 (21,10)–(43,32) + 三路 + 六据点（A/B/C 链）。目标：形成**主殿核心圈 / 外环走廊 / 三片主题区**的一体化大地图，并支撑 E4、E5 的终局复用。

### 6.2 结构（原型建议）

| 区域 | 内容 | 解锁条件 | 风险 / 收益 |
| --- | --- | --- | --- |
| 主殿核心圈 | 核心 (32,21)、T1–T4、后勤整备区 | 开局 | 最高安全，基础收益 |
| 外环走廊 | A/B/C 六据点、拐点与柱 | W1 起 | 中风险，资源与经验 |
| 森林区（西，A 链外） | 资金、基础材料 | 清 A1/B1/C1 后 | 低危资源区 |
| 冰川区（东，B 链外） | 控制类设施图纸（减速/阻断） | 清对应走廊据点后 | 中危控制区 |
| 火山区（南，C 链外） | 高收益设施、远征入口 | 中后期 | 高危爆发区 |

三片主题区对应蓝本的森林 / 冰川 / 火山，但**只做功能与风险分层**，不复制其地图。

### 6.3 规则

- 核心不动（沿用）；主题区是**探索目的地**，不是第二战场，地图底色不是自由风筝区（沿用 v0.1）；
- 距离—收益—风险梯度：越远收益越高、回防距离越长；回城仅战备期可用、受击打断（沿用 v0.1）；
- 区域状态机沿用据点状态：未进入 → 激活守军 → 清空 → 奖励已领取 →（E4/E5）可布防 / 可作为远征集结地；
- 守军与波次进攻怪计数互不污染（R7 沿用）；
- 性能：区域分块加载；同屏软上限 80 沿用；大地图必须通过最坏情况压测后再扩内容。

### 6.4 验收

1. 从主殿到最远区域往返时间 ≤ 一个探索窗口（B0+R）的 1.5 倍，否则该区域无人会去；
2. 三片主题区各有独立访问动机，不能只存在一条最优探索链；
3. 首次游玩靠小地图与路标不迷路；回防提示在距离核心较远时可见（沿用 v0.1）。

## 7. E4 终局考验波：让地图不废

### 7.1 设计

在 W20 Boss 清空后追加一段**考验波**：敌人从已解锁区域（森林 / 冰川 / 火山）与三路入口多向向心推进，而不是只从 W/E/S 三路来。

目的：**让探索过的地图在终局再次参与**（对应用户原话「这些地图也不是用过即废」），同时把 E2 的构筑与 E3 的地图知识一起收束。

### 7.2 规则（原型建议）

| 项 | 规则 |
| --- | --- |
| 触发 | W20 Boss 清空后；至少有一个主题区被解锁时才触发，否则直接胜利结算 |
| 出怪 | 从已解锁区域 + 三路入口按配比出兵；可分批错峰 |
| 路线 | 向心推进；允许穿过玩家清过的房间；路径必须可寻路（沿用 v0.1 卡怪回退） |
| 预警 | 独立 ≥ 8 秒预警；不压缩探索窗口 |
| 胜利 | 考验波清空、有害反应结算完成、角色与核心存活 |
| 失败 | 角色 / 核心归零立即失败；同帧失败优先（沿用 v0.1） |
| 演出 | 终局片段在考验波开波前播放；不遮挡入口与预警（沿用 v0.1 演出规则） |

### 7.3 未清据点的处理（二选一，【待确认】）

- **方案 A（收益导向，推荐起步）**：未清据点不参与考验波；清空并布防的据点提供支援（定点炮台 / 补给 / 拦截）；
- **方案 B（风险导向）**：未清据点在考验波额外出一支小队，强化「清房」的必要性；
- A 更稳（不惩罚探索不足的玩家），B 可留作高难变体。

### 7.4 验收

1. 有探索与无探索玩家在考验波的压力差**可感知但不悬殊**；
2. 外圈路径不会导致敌人卡死、超时或越过生成上限；
3. 考验波的预警、演出与胜负判定与 v0.1 完全一致。

## 8. E5 大远征与房间限伤

### 8.1 定义（来自聊天记录，【待确认】）

> 「加一个大远征啊，敌人得整个走一圈但是每个房间有限伤」

- **大远征**：敌人成队沿大地图**完整走一圈**（逐房间推进），而不是直接攻城；
- **房间限伤**：每个房间对防守方造成的伤害存在上限，达到上限后本房间不再产生该类伤害。

### 8.2 为什么这么设计

1. 让**路程成为玩法**：距离 = 时间 = 削弱与转移的窗口；
2. 房间限伤让远征变成「逐房间消耗」，避免单点秒杀，给玩家读局势与换位的空间；
3. 与 E4 衔接：大远征可以作为考验波的首个落地形态，让地图真正「用过不废」。

### 8.3 原型规则（建议）

| 项 | 建议 |
| --- | --- |
| 编制 | 3–5 支远征队，每队含推进 / 远程 / 破阵单位；Boss 作为可选压轴 |
| 路线 | 外环一周：森林 → 冰川 → 火山 → 主殿（可按章节反向或错峰） |
| 行进 | 在房间内停留 ≤ X 秒（建议 12–20s）或被清空后推进；停留期间攻击设施与角色 |
| 房间限伤 | 每房间对**核心**的累计伤害上限 C_room（建议 = 核心耐久的 8%–12%）；达到上限后该房间的敌人不再伤核，只能推进或攻击角色 / 设施 |
| 刷新 | 限伤按波 / 按房间重置；状态绑定 wave_id，反复进出同一房间不能刷掉限伤 |
| 结算 | 死亡、掉落、奖励、清波计数各一次（R6 沿用） |
| 时长 | 远征总时长上限（建议 ≤ 90s），超出后的处理方式【待确认】 |

### 8.4 反例与风险

| 风险 | 处理 |
| --- | --- |
| 龟缩一个房间 | 房间限伤使龟缩只能拖延不能取胜；停留时间上限强制推进 |
| 绕图风筝 | 房间边界 + 停留规则 + 关键节点卡位；不靠无限风筝获胜 |
| 性能峰值 | 远征队 + 设施 + 玩家同屏；先压测再定编制与批次 |
| 结算重复 | 死亡 / 掉落 / 奖励一次性去重（R6），守军与波次计数分离（R7） |
| 玩家看不懂 | 限伤与远征进度必须有独立 UI（每房间已造成/剩余限伤），不伪造战报（R9） |

### 8.5 验收

1. 日志可验证：每房间实际对核心伤害 ≤ C_room；
2. 三种防线强度下，远征时长与失败点分布合理（不能全部「秒过」或「必败」）；
3. 失败优先级与 v0.1 一致；远征期间的暂停、升级、演出跳过均冻结全部模拟（R8）。

## 12. 验收清单（可复现）

| 测试场景 | 预期结果 |
| --- | --- |
| 速清一波（T < B） | 结算一次奖励；探索窗口 = B0 + R；不结转 |
