## 0 一页总纲

**一句话**：把「人」和「塔」的成长拆成两棵可以互相点亮的技能树；把「地图」从一张主殿扩成三片几何与地形完全不同的战区，让地形本身成为战斗力。

**三条设计红线**：

1. **加点必须改变行为，不只是改数字**——每个节点至少改变「空间、时间、目标选择、状态、资源」中的一项（对齐涌现规则 R1–R9）。
2. **地形必须有代价与收益**——没有纯装饰的地形物件；每个地形元件要么伤、要么挡、要么改路径、要么给资源。
3. **一切可被日志验证**——地形效果、树节点效果都要能被测试用例断言，不能只靠「感觉」。

**四个新玩法模式的定位**：

# 第一部分 · 大构筑

## 1 为什么要把三选一换成双池技能树

现有成长是「幸存者式三选一」：升级给 3 个随机候选，选 1 个。它在 20 波守核里有两个硬伤：

1. **构筑不可预谋**：玩家无法围绕「我这局要打控制流」提前规划，只能被随机推着走；塔与人的成长彼此无关，塔只是「花钱升级」。
2. **点数浪费**：塔的成长（升级 ×2 + 模块）与人的成长（三选一）是两条平行线，玩家的操作与建的塔之间没有互相强化的回路。

**改成双池后的变化**：
- 玩家有**可规划**的树：先拿什么、为哪条分支让路，是本局的开局决策；
- **人的点数能点亮塔的行为**（协同节点），**塔的点数能反哺人**（例如机巢提供护盾）——形成「人—塔」闭环；
- 三选一不是删掉，而是**降级为「战利品」**：某些节点给「一次性免费点」，保持惊喜感但不破坏规划。

## 2 双池结构总览

```
┌─────────────────────── 角色池 RP（人） ───────────────────────┐
│  通用线（4 支 × 5 节点）        │  角色线（所选角色 × 6 节点 + 觉醒）│
│  生存 / 机动 / 火力 / 后勤      │  例：小猫咪 = 猫爪线 + 鱼骨线      │
└───────────────┬───────────────────────────┬───────────────────┘
                │  协同节点（跨池，见 §5）      │
┌───────────────┴───────────────────────────┴───────────────────┐
│                       炮台池 TP（塔）                          │
│  6 个炮台家族，每家族：基础 → 分支 A / B → 进阶 → 专精           │
│  星爆猫炮 / 豆勇士炮 / 灵猴炮 / 巨掌炮 / 叶灵炮 / OTTO 机巢      │
└───────────────────────────────────────────────────────────────┘
```

- **RP（角色点）**：只点角色树；`1 点/波`，每 5 波 +1（20 波 ≈ 24 点），据点首清各 +1（+6）→ 单局上限约 **30 点**。
- **TP（炮台点）**：只点炮台树；据点首清 +2（12）、每 5 波 +1（4）、考验波 +1、远征每队 +1（3）→ 单局上限约 **20 点**。
- **神典点（稀有）**：考验波与远征首通给，可**越过前置**点一个节点（用来做「本局独一档的选择」）。

> 设计意图：两池总量都**小于**树的全节点数（角色树 ≈ 42 节点、炮台树 ≈ 6×4=24 节点），保证「每一局都必须放弃一些东西」。

## 3 炮台 = emoji 角色的战斗能力

| 角色（原项目） | 炮台家族 | 分支 A（专属技 → 塔形态） | 分支 B（第二技 → 塔形态） | 家族气质 |
| --- | --- | --- | --- | --- |
| 小猫咪 😺（弹幕高手，高暴击高机动） | **星爆猫炮**（速射血统） | **星爆猫爪**：命中有概率积「连击」，满层下次攻击打出 200% 范围星爆 | **穿透鱼骨**：穿透 2 目标，命中后 30% 概率弹射一次 | 单体点杀 / 弹幕铺场 |
| 黄豆勇士 😆（爆炸专家，高血低暴击） | **豆勇士炮**（范围血统） | **豆芽陷阱**：周期性在射程边缘埋雷，敌人踩中范围爆炸 + 击退 | **手雷连投**：抛射，落点溅射；每 3 发第 4 发变为「大雷」 | 区域拒止 / 定点爆破 |
| 灵猴大圣 🐵（极速连击，闪避大师） | **灵猴炮**（速射血统） | **分身打击**：周期性召唤分身，发射多发低伤弹 | **连击拳**：命中后弹射到 1.5 格内下一个目标（链式，逐跳衰减） | 多目标覆盖 |
| 无敌巨掌 🤚（力大无穷，范围碾压） | **巨掌炮**（范围血统） | **掌风波**：穿透冲击波，越远伤害越低但击退越强 | **太极拳**：化劲——在塔前 2 格生成反制领域，弹回敌方弹体 | 重击推进 / 反制 |
| 自然之灵 🍃（冰霜控制，自然之力） | **叶灵炮**（控制血统） | **霜瑟风暴**：范围减速 + 叠层冻结（3 层冻结 1 秒） | **藤蔓穿刺**：多重穿透 + 25% 追踪，对已减速目标伤害 +40% | 控制 / 收割 |
| OTTO♿（召唤大军，以众克敌） | **OTTO 机巢**（支援血统） | **盒子**：部署子炮台（上限 2），复制**相邻**炮台分支的最弱效果 50% | **大象踩踏**：周期性范围踩踏（1.5× 伤害 + 0.4 秒硬直） | 召唤 / 场地压制 |

**每个家族的树结构一致**（4 级 = 建造即得 T0 + 3 点点满）：

| 层级 | 消耗 | 内容 |
| --- | --- | --- |
| T0 基础形态 | 建造即得（80/90/110 资金，继承） | 现有三种塔的基准数值 |
| T1 分支选择 | 1 TP | 二选一：走 A 还是 B（原本的 6 个「模块」并入这里，见 §6） |
| T2 分支强化 | 1 TP | 沿所选分支加深：数值 + **一个新行为** |
| T3 专精 | 1 TP | 该家族的「大招」节点：要么极端化，要么补一条对立能力 |

> 为什么是「每塔 3 点」：4 个建造槽 × 3 点 = 12 点，加上第 4 类「支援设施」（§4.3）共 16 点——正好让 20 点 TP 有取舍，不能全点满。

| 角色 | 线① 基础技 | 线② 基础技 | 线③ 专属 I | 线④ 专属 II | 线⑤ 专属 III | ⑥ 觉醒 |

| 黄豆勇士 | 手雷（附带击退） | 力场护盾 | 豆芽陷阱 | 连锁豆芽（陷阱触发范围 +40%） | 豆田（同时存在上限 3 → 5） | 主动技：击退 → **引爆全场陷阱** |

## 5 跨池协同（人 ↔ 塔 的回路）

**协同节点**是双池设计的关键：它们只出现在**两棵树交界处**，用「人」的点解锁「塔」的新行为，反之亦然。

| 协同节点 | 需求 | 效果 |
| --- | --- | --- |
| 战术标记 | 火力线② + 任一炮台 T1 | 被你击退过的敌人，3s 内被塔视为「优先目标」 |
| 冷却共享 | 机动线② + 叶灵炮 T1 | 塔的减速命中敌人时，你的击退冷却减 0.15s（上限 1.5s/次） |
| 弹道接管 | 后勤线⑤ + 巨掌炮 T1 | 塔的攻击可以继承你的穿透层数（最多 +1 穿透） |
| 产能联动 | 后勤线④ + 后勤站 | 据点的星砂产出 +1（每次首清） |
| 觉醒同步 | 任意觉醒 + OTTO 机巢 T3 | 你释放主动技时，盒子同步释放一次弱化版 |

> 设计目的：让「先点人还是先点塔」变成真正的开局抉择——协同节点是两边都点的人才拿得到的超额收益。

## 7 局外成长（跨局不影响平衡）

- **神典点**：跨局累积，用来解锁「树的新层级上限」与「英雄觉醒」——**只给更多选择，不给更高数值**；
- 局外点上限与首通挂钩：每个地区首通 +1 层级上限（极光 3 / 沼泽 4 / 沙漠 5），把「打新地图」变成成长的钥匙；
- 图腾/遗物保留原功能，但改为「开局携带 1 个」的**起手件**（对应原项目「图腾最多装备 3 个」的降档版本）。

## 8 洗点与容错

| 规则 | 数值 |
| --- | --- |
| 洗点时机 | 仅战备期、且核心耐久 > 0；战斗与预警期禁用 |

## 9 三个地区：几何先行

| 地区 | 几何 | 改造自 | 记忆点 |
| --- | --- | --- | --- |
| **极光地区** | 六边形蜂巢（hex, axial 坐标，6 邻接） | 冰川地区 | 极光带周期涨落，站带内充能 |
| **幽灵诅咒沼泽区** | 方格（square，4/8 邻接） | 森林地区 | 迷雾 + 诅咒值，地形会「养鬼」 |
| **沙漠区** | 环形（ring, sector × ring 坐标） | 火山区 | 沙暴周期，遗迹与流沙 |

**几何即玩法**：六边形让「包夹」与「最小拦截点」变难（3 个敌人可从 4 个方向逼近）；方格让「堵口」与「掩体排布」最强；环形天然形成「向心推进」与「绕圈放风筝」的对抗。

### 9.1 坐标与距离

| 地区 | 坐标 | 距离 | 备注 |
| --- | --- | --- | --- |
| 极光 | axial `(q, r)`，立方坐标转换 | `( |dq| + |dr| + |dq+dr| ) / 2` | 平顶六边形；每格仍计为 1 逻辑格，与现有 `coordinate_scale` 兼容 |
| 沼泽 | 现有 `(x, y)` 整数格 | 曼哈顿（寻路）/ 欧氏（射程） | 可开启「对角移动」变体做难度分层 |
| 沙漠 | `(ring, sector)` 环坐标，环 0..R、扇区 0..N-1 | `|ring 差| + 扇区差（取模取小）` | 圆心是「神殿台基」，外环是入口 |

### 9.2 生成算法（种子可复现）

**通用管线**：`地区模板 → 房间图（RoomGraph）→ 走廊（最小生成树 + 1~2 条环路）→ 地形填充（噪声 + 约束求解）→ 地标/掩体/危险区布点 → 可达性校验 → 种子存档`。

| 地区 | 生成细节 |
| --- | --- |
| 极光 | 蜂巢簇（每簇 7 格）→ 簇间单格「冰桥」连接；极光带沿「磁力线」正弦铺设，覆盖约 40% 格；离子柱成列；冰壳层在走廊口 |
| 沼泽 | 方形房间 + 泥沼斑块（噪声阈值）；枯树/芦苇成排做掩体；诅咒石放房间角落；净化灯分布在中继点（位置由生成器保证「任意两点间距 ≥ 6 格」） |
| 沙漠 | 同心环（3~5 环）+ 放射走廊；遗迹墙沿弧线成段；流沙布在环与环的接缝；绿洲固定 1~2 处且不落在走廊上 |

**约束（必须通过校验，否则重掷）**：① 核心可达；② 三入口到核心均可达；③ 掩体不封死（任一掩体被破坏后仍连通）；④ 危险地形不覆盖核心 3 格内；⑤ 建造槽不被地形占满；⑥ 同种子同布局。

## 10 地形元件：每个都参与战斗

### 10.1 极光地区（六边蜂巢）

| 地形 | 规则（原型值） | 玩家怎么用 | 敌人/塔怎么用 |
| --- | --- | --- | --- |
| 冰壳 | HP 40，可击碎；破坏后成「洞口」 | 砸壳开洞，给敌人放一条「诱饵路径」 | 敌人绕行；洞口附近塔获得额外射界 |
| 离子柱 | 每 2s 放电链（跳 3 目标，6 伤害） | 把敌人推到两根柱之间吃连锁 | 冰霜类攻击可引爆柱（半径 3 格，30 伤害） |
| 极光带 | 每 20s 相位移动，覆盖约 40% 格；带内角色技能冷却 -30%、敌人移速 +20% | 追着极光带打架，换技能节奏 | 敌人在带内免疫减速；塔在带内攻速 -10% |
| 裂隙 | 掉入即减速 60% 且每秒 3 伤害，2 秒后自动爬出 | 用击退把敌人推进裂隙 | 冲锋怪被裂隙中断冲刺 |
| 霜华 | 移速 ×0.85，转向有惯性 | 拉长敌人的行进弧线 | 击退距离 +30% |

### 10.2 幽灵诅咒沼泽（方格）

| 地形 | 规则 | 玩家怎么用 | 敌人/塔怎么用 |
| --- | --- | --- | --- |
| 泥沼 | 移速 ×0.6；站在里面的塔射程 ×0.9 且每秒 -1 HP | 把敌人拖进泥沼，用减速塔叠控 | 沼泽潜伏者可从中钻出 |
| 毒沼 | 每秒 5 伤害（敌我通吃）；被净化后变浅水 | 逼迫敌人改道；配合击退 | 敌人会主动绕开毒沼 |
| 诅咒石 | 3 格内每秒 +12 诅咒值；满 100 召唤 1 只幽灵 | 主动踩上去「拉鬼」来打工？不——这是陷阱 | 咒术师会给石头上咒，扩大其范围 |
| 净化灯 | 半径 6 格：诅咒值 -20/s、迷雾消散；HP 60 可被摧毁 | 保住灯是主线之一 | 幽灵被照明时才可被锁定 |
| 迷雾 | 玩家视野 6 格；塔射程 ×0.75 | 用灯换视野，用「全域应答」预判路线 | 幽灵在雾中隐形 |
| 枯树/芦苇 | HP 50 掩体 | 借掩体挡远程、卡冲锋 | 远程怪会绕到掩体侧翼 |

### 10.3 沙漠区（环形）

| 地形 | 规则 | 玩家怎么用 | 敌人/塔怎么用 |
| --- | --- | --- | --- |
| 流沙 | 每秒「下沉」1 层，3 层被掩埋：3 秒无法移动 + 15 伤害 | 推敌人入流沙换时间 | 沙虫无视流沙；重装敌人下沉更慢 |
| 遗迹墙 | HP 120，破坏掉 1~3 星砂 | 拆墙开路或留墙挡线 | 塔的弹道被墙截断（继承现有墙柱规则） |
| 沙暴 | 每 45s 持续 12s：视野 5 格、塔射程 ×0.7、敌人移速 +15% 且击退距离减半 | 提前布防、把爆发技留给沙暴期 | 秃鹫在沙暴中可越过掩体 |
| 绿洲 | 半径 4 格：玩家回血 2/s；火属性伤害 ×1.5 | 补给点，也是危险点 | 木乃伊在绿洲不被复活（圣水） |
| 驼峰岩 | 高台：站在上面射程 +1.5 格，但被远程视为「暴露」 | 获取射程优势 | 沙虫可掀翻岩体（改变地形） |

## 11 地形如何「真正融入」（规则矩阵）

| 交互维度 | 规则 | 例子 |
| --- | --- | --- |
| 地形 × 弹道 | 墙/柱/遗迹墙截断弹道（继承）；高低差（驼峰岩）改变命中 | 巨掌炮的穿透波被遗迹墙截断 |
| 地形 × 状态 | 地形施加状态可被技能叠加/清除 | 霜华 + 霜瑟风暴 = 冻结更快 |
| 地形 × 击退 | 击退沿施力方向，碰墙停止；特殊地形放大/免疫 | 霜华 +30% 击退；沙暴期击退减半 |
| 地形 × 敌人 AI | 敌人按「代价最小路径」行进，会绕毒沼/躲离子柱 | 咒术师会主动绕开净化灯 |
| 地形 × 建造 | 建造槽被地形约束：泥沼槽不推荐、驼峰岩槽加射程 | 沙漠环上的槽位天然强 |
| 地形 × 波次 | 地形在战备期变化（极光相位、沙暴预警、雾的浓淡） | 战备期看到沙暴倒计时，决定这波怎么打 |
| 地形 × 房间限伤 | 每个房间的核心限伤独立；地形决定「守哪一间最划算」 | 沼泽房限伤低但地形强，沙漠房限伤高 |

## 12 大地图与模式的组合

| 模式 | 地图 | 地形使用 |
| --- | --- | --- |
| 经典防守 | 主殿（现状） | 不启用地区地形 |
| 三房间考验 | 随机三角色几何各一间 | 每间只开 2~3 个地形元件（教学） |
| 外圈远征 | 三队绕行全图 | 全地形 + 房间限伤；地形决定绕行难度 |
| 神殿扩展 | 三片地区全开 | 全地形 + 技能树 + 据点/考验波 |

**远征路线（示例）**：`主殿 → 极光（冰桥）→ 沼泽（灯链）→ 沙漠（环廊）→ 主殿`，三队分别走三条不同几何的短环，逼迫玩家在「同一时间只能守一处」的前提下做取舍。

## 15 验收（可复现）

| 场景 | 预期 |
| --- | --- |
| 树预算 | 单局 RP/TP 上限与节点总数关系正确；不存在「点满一切」的路线 |
| 分支互斥 | 同一塔的 A/B 不可同时点；换分支需洗点并扣费 |
| 协同 | 未满足前置时协同节点不可点；满足后效果进入属性计算 |
| 地形·冰壳 | 破坏后路径连通性被重新校验；敌人改道且不卡死 |
| 地形·净化灯 | 灯灭后迷雾恢复、幽灵重新隐形；灯可被摧毁且只结算一次 |
| 地形·流沙 | 3 层掩埋后 3 秒无法移动；击退进入的敌人同样生效 |
| 地形·沙暴 | 周期与效果可被日志断言；不因演出暂停而错拍 |
| 几何 | 三种几何的同种子重放一致；寻路与视线结果符合各自距离定义 |
| 生成器 | 一万次随机种子：可达性校验 100% 通过、无掩体封死、无危险区压核心 |
| 性能 | 大地图 + 80 单位 + 全地形效果下帧率不崩（沿用软上限与画质档位） |

## 17 风险与对策

| 风险 | 对策 |
| --- | --- |
| 六边形/环形使寻路与视线成本翻倍 | 先做方格（M2），几何抽象成「邻接 + 距离 + 视线」三个接口，六边与环形只换实现 |
| 树太大 → 玩家看不懂 | 树永远只展开「当前可点」的两层；其余折叠成图鉴；样例构筑内置 3 套推荐 |
| 地形要素过多 → 战斗读不懂 | 每个地区同时生效的地形元件 ≤ 3 种（其余作为背景）；危险地形必须有独立音效与地面标记 |
| 与现有测试冲突 | 所有新增规则补测试；旧事件名（`UpgradeOffered` 等）保持不变 |
| 数值失控 | 树节点全部走同一份乘算表；每加一个节点必须写明「代价」 |
