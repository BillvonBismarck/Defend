## 4 点数、等级换算与预算

| 项 | 规则 |
| --- | --- |
| 源技能 `maxLevel` 换算 | 3 级 → 树内 2 级；5 级 → 树内 3 级；4 级 → 2 级 + 专精 |
| RP 总量 | 升级 1 点/级（阈值 20+10×(级−1)）＋ 每 5 波 +1 ≈ 24–30 |
| TP 总量 | 据点首清 +2/房（6 房 12）＋ 每 5 波 +1（4）＋ 考验 +1 ＋ 远征 +3 ≈ 20 |
| 树的总节点 | 角色线 6×6=36 ＋ 通用新增 7 ＋ 炮台 8×3=24 ⇒ **不可能点满**，必须取舍 |
| 洗点 | 战备期，`10 + 5×次数` 星砂；不返还已建分支的 20 星砂 |

## 5 设施联携（借用「符文共鸣」范式）

原项目 6 组共鸣的写法（两个来源 + 一个组合效果 + 明确参数）可直接搬到设施上。**联携只读公共字段（距离、状态、生命），不写专用组合彩蛋**：

| 联携 | 组合 | 效果（原型值） | 源参照 |
| --- | --- | --- | --- |
| 霜火联动 | 减速塔 + 范围塔 | 被减速目标受到的范围伤害 +25% | `shadow_fission` 的"额外弹幕"结构 |
| 盾墙联动 | 路障 + 维修站 | 路障被修复时，4 格内设施获得 1 层护盾（每波 1 次） | `iron_medic` |
| 弹药联动 | 供能站 + 速射塔 | 供能范围内的速射塔穿透 +1 | `overclock_perfect` |
| 陷阱联动 | 拒马（盒子）+ 范围塔 | 盒子复制范围塔的溅射（比例 50%） | `phantom_storm` |
| 击退联动 | 击退台 + 减速塔 | 被击退的敌人落入减速区时额外减速 15%（上限 50%） | `thunder_loot` |
| 后勤联动 | 维修站 + 后勤（主殿） | 每波第一次维修免费 | `flame_rebirth` |

> 与 `Reactions` 的接口：联携效果产生的伤害/状态必须走公共提交顺序（合法性 → 遮挡 → 位移/状态 → 伤害 → 死亡 → 波次），且一次效果只结算一次。

## 6 局外层（图腾 / 遗物 / 符文）

| 素材 | 建议 | 理由 |
| --- | --- | --- |
| 遗物 10 个 | **局外加点**：每级 +0.2%~0.5%，与"神典点"共用层级上限（首通极光 3 / 沼泽 4 / 沙漠 5） | 数值小、可长期；不破坏局内树取舍 |

| 每 5 波天赋 | **改为发放点数**（+1 RP / +1 TP）并解锁树层 | 用户明确要求「天赋改为加点」 |
