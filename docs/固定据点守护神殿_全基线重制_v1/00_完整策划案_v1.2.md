## 2 核心玩法：循环与状态机

### 2.1 一句话与体验支柱

**一句话**：你是神殿唯一的守卫者，在三路来敌与三片野外之间分配时间；用高效的清波换取探索窗口，用探索所得把神殿与外圈变成一座真正打得赢的防线。

| 支柱 | 具体要求 | 反例（不允许） |
| --- | --- | --- |
| 时间即资源 | 清波越快，下一段探索越长；提前开波作废剩余 | 探索时间不能存银行、不能刷 |
| 核心不可弃 | 核心耐久独立、位置固定、警报优先于一切表现 | 不能用移动据点、无敌或暂停规避守核 |
| 构筑要选择 | 双池点数总量小于树的总节点 | 不存在"点满一切"的路线 |
| 地形是玩法 | 每块地形至少有一项战斗作用 | 不做纯装饰地形 |

### 2.2 主循环（与代码一致）【实现】

```
秒级：移动/索敌 → 攻击与主动技 → 拾取 → 升级点判定 → 检查残敌
波次级：战备 15s（含速清奖励，上限 30s）→ 预警 8s → 进攻（基准 30/45s）→ 清波结算
章节级：选场景 → 开场 → 20 波守核 → 考验波 → 三队远征 → 胜利/失败 → 结算
```

### 2.3 状态机与暂停源【实现】

- **状态**：`PREPARATION`（战备）→ `WARNING`（预警）→ `ATTACK`（进攻）→ `RESOLVE`（结算）→ 下一波 / 终局。
- **暂停源集合**（互不覆盖）：`story`、`upgrade`、`module_choice`、`manual`、`logistics`、`map`、`technical`、`rules`、`recap`。任一存在即冻结全部模拟（含冷却、弹体、远征、反应队列）。
- **时间口径**：基础战备 15s；速清奖励 `clamp(B − T, 0, 15)`；探索窗口 `15 + R ≤ 30`；提前开波作废剩余；预警独立计满 8s（提前开波时补足）。

### 2.4 胜负与优先级【实现】

- **胜利**：第 20 波清空（若满足考验条件则考验波也清空）、有害反应结算完成、角色与核心存活。
- **失败**：任意时刻角色生命 ≤ 0 或核心耐久 ≤ 0；**同帧失败优先于 Boss 死亡**。
- **清波判定**：生成队列执行完成 且 本波存活进攻怪为 0；据点守军与远征单位不混入计数。

## 3 战场、房间与地形

### 3.1 从固定主殿到房间制战场【设计】

- 战场改为**多边形房间制**：一次只激活 1–3 个房间（当前房 + 相邻房），模拟仍由 `Run` / `Combat` 单场景驱动，不改权威结构。
- **主空间 = 十二边形房**：神殿核心（耐久 1000，半径 1.6）固定在房间中心，**只与三个三角闸室相连**（端口方位 0° / 120° / 240°），度数恒为 3。
- 三个三角闸室 = 三路入口 **W / E / S**；波次仍从闸室灌入主空间，**三路守核机制不变**。
- **后勤区（旧坐标 (25,2)–(39,8)）废置**：建造与修复就地完成，"回城"改为传送锚点（§3.6）。
- 旧固定布局（主殿 + 外圈六房 A1…C2）作为 `legacy_v02` / `sanctuary_expansion` 场景保留，新场景 `polygon_expansion` 承载本节设计。

### 3.2 三种房间的几何与槽位【设计】

统一**边长 s**，单位格 **u = s/4**（三角房恰好 4×4 = 16 个单位三角）。

| 形状 | 边长 | 面积（单位三角） | 面积比 | 外接圆 R | 内切圆 r | 槽位 | 可用端口 | 内容定位 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 三角 T | **10u** | **100**（精确） | **1.00** | 5.774u | 2.887u | 1（中心） | 3 | 闸室：小怪波次 |
| 六边 H | **6u** | **216**（精确） | **2.16** | 6.000u | 5.196u | 3 | 6 | 精英房：两波小 Boss + 传送锚点 |
| 十二边 D | **4u** | **400**（阶梯取整到 4.00×） | **4.00** | 7.728u | 7.464u | 12 | 6（仅格点边） | 核心房：主空间 / 群系超级 Boss |

- **边长不可变**：全图只有这三种房间、各一个尺寸；难度只能靠房间数 / 环路 / 单向锁 / 小 Boss 波数 / 敌人系数调。
- **边长倒置 10 : 6 : 4** 是面积比 1 : 2 : 4 的数学后果（面积系数差 25.86 倍）；内切半径 2.9 < 5.2 < 7.5 u，视觉上仍是"三角最小、十二边最大"。
- **走廊**：宽恒 2u；长 ∈ {2u, 3u, 4u}（优先 3u，同链相邻差 ≤ 1u）；轴只取 6 个奇数方向，长边永远与格点平行。

- **槽位密度**：三角 0.010、六边 0.014、十二边 0.030（槽/单位三角）—— 核心房火力密度最高（决战地），三角房是单点碉堡。
- **中心距**（L=3u 时）：三角–三角 8.77u、三角–六边 11.08u、三角–十二边 13.35u、六边–六边 13.39u、六边–十二边 15.66u、十二边–十二边 17.93u；连接点恒为边的中点。
- **方位系统（坐标系）**：走廊轴只取 6 个奇数方向（30°/90°/…/330°），房间朝向由所用端口决定，无需自由旋转参数。
- **十二边用阶梯收边**：三角网格只有 3 个方向、凸多边形最多 6 条边，12 边房间不可能格点精确；故取**面积精确 400 单位三角**、边界 1u 台阶（锯齿只影响轮廓，不影响面积）。

### 3.6 传送与"后勤区废置"的替代【设计】

- **传送锚点**：六边形精英房清空后生成；**已激活锚点之间双向传送**；冷却 20s；**进攻波次期间与房间战斗实例中不可传送**。
- **回城语义变更**：原"回后勤区"改为"传送回主空间"；`RecallStarted / RecallCompleted / RecallCancelled` 事件名保留，语义调整（不再依赖后勤区坐标）。
- **就地建造**：任何已解锁槽位所在房间即可建造、升级、拆除与维修，`DefenseSiteAvailable` 的判定改为"房间槽位 + 解锁状态"。

### 5.2 角色池（RP）

- **通用线**：保留已实现 10 节点（`power/rapid/pierce/blast/pulse/frost/vitality/mobility/synergy/relay`）；从素材补 7 个新节点（多重射击、弹射弹、巨弹强袭、击退冲击、力场护盾、生命恢复、磁力增强）。**8 个通用型技能不重复建节点**（数值已被现有节点覆盖）。
- **角色线**：每个角色 6 节点 = 自身 5 技能中的 3 个基础 + 1 个进阶 + 1 个专属 + 觉醒；**专属技不可被其他角色点到**。例（小猫咪）：多重射击 → 穿透弹 → 暴击提升 → 射速提升 → **星爆猫爪** → 觉醒（猫爪乱舞）。

### 5.4 点数预算

- **RP**：升级 1 点/级（阈值 `20 + 10×(等级−1)`）＋ 每 5 波 +1 ⇒ 单局 ≈ 24–30；
- **TP**：据点首清 +2/房（12）＋ 每 5 波 +1（4）＋ 考验 +1 ＋ 远征 +3 ⇒ ≈ 20；

- **洗点**：战备期、`10 + 5×次数` 星砂；不返还已建分支的 20 星砂。

## 8 表现、反馈与演出

### 8.1 HUD、双层地图与警报【实现 + 设计】

- **常驻 HUD**：角色生命、核心耐久、当前波/20、战备或预警计时、经验、资金、主动技状态；核心受击闪烁 + 方位箭头 + 独立音效；低于 30% 耐久的紧急提示。
- **小地图（Radar 扩展）**：常驻右下角，按房间几何等比缩放绘制**真实多边形轮廓** + 槽位占用 + 墙段 + 敌人点 + 出口方向 + 核心/玩家。
- **大地图（新增）**：战备期打开，显示全域拓扑（房间类型图标、清空状态、门状态、传送锚点、当前所在、未解锁虚影）；打开时进入暂停源 `map`。
- **传送锚点**：两层地图均显示；已激活为实心、未激活为空心。
- **后勤区移除的 HUD 影响**：删除后勤整备区入口与"回城"按钮，改为"返回主空间（传送）"；建造/修复面板就地弹出。
- **升级卡**沿用实际数值前后对比（`Progression.Preview`）；三选一保留为**战利品免费点**（Q1=a 已决），升级本身只给 RP。

### 8.2 因果反馈【实现】

- 战报只用已提交事实：来源、位置、目标、实际伤害/修复/支出；
- 阶段与局末选 1–2 条真实事件链（`Feedback.Select`），不伪造"避免的伤害"；
- 属性提示去重、可关闭；`SlowClearHint` 在连续两波慢清时提示"考虑先修复或布防"。

### 8.3 演出【缺口】

现状：`View:BuildStory` 用 emoji + 几何背景 + 整段缩放，具备播放/跳过/短版/回看与暂停冻结。
目标：分镜 + 分层素材（前景/人物/背景）+ 镜头运动 + 表情/关键动作 + 配音与声音节拍；阶段事件与事实镜头按定稿接入。**未完成前不得宣称 C04 完成。**

### 8.4 性能与画质【实现】

五档画质（省电/流畅/均衡/精致/全量）只降特效不降规则；存活软上限 80；FPS 采样与自动降级；场景化性能预算见 §10。

### 9.2 提交顺序与身份【实现】

`合法性 → 空间/遮挡 → 位移/状态 → 伤害 → 死亡/反应 → 波次/据点 → 失败优先 → 反馈`；
死亡/掉落/奖励/清波各自去重；`root_action_id` 贯穿连锁但不合并不同死亡；据点守军与波次进攻怪身份分离（`room_id` vs `wave_id`）。

### 9.3 场景与字段【实现】

- 场景级：`scenario_id / rules_version / map_size / map_origin / total_waves / record_namespace`；
- 房间级：`region_id / guard_profile / reward_kind / module_reward / defense_slots / challenge_target`；

- 塔级：`module_id / module_revision / build_spend / upgrade_spend / service_spend`；
- 远征：`route_id / waypoints / stops / engage_duration / room_caps / final_target / current_room_id / damage_ledger`。
