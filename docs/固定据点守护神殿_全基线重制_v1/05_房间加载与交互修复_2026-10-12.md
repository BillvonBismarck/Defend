# 房间加载、性能与横屏交互修复

用户本轮要求：解决卡顿，先做好单房间加载；更多房间与环形连接；日常只互动最近炮台，全场统计放进内置浮窗；大地图进入地图界面；统一横屏 16:9–20:9；Maker 推送构建后实测。

## 实现

- `RoomIndex` 为房间、走廊、外墙和门建立空间索引。碰撞精度、半径与连续扫掠仍由原精确几何判定；切边和路径连接只检查相关候选，门变更使连接缓存失效。
- 守军内容进入房间时初始化，只驻留当前探索房间。战场和小地图只绘当前房及门口连接；廊道视图选所属连接端点。已清房状态、拓扑与碰撞元数据保留，不因离房丢失奖励、设施或锚点。守核进攻继续模拟，不能以离房冻结敌人。
- 默认场景难度 D1–D5 为 49 / 61 / 73 / 85 / 97 房间；生成器增加多节点分叉和独立环簇入口，保留主空间三入口与三个地区核心。旧场景的原拓扑样板保留。
- 地图按钮、M 和点击小地图都进入同一全域地图。地图固定在窗口主区域；支持缩放、平移、全图复位。战斗中可查看，传送仍由战备期与锚点规则授权。
- 常驻炮台统计浮窗显示全场数量与累计输出，点击查看每塔位置、耐久、输出和属性；统计不授予远程交易权限。E/F 与布防按钮统一选择当前房间最近槽位，布防面板不再列全图房间。
- 虚拟摇杆改为 1280×720 横屏基准；沿用项目已设置的 landscape 发布方向、UI.Scale.DEFAULT 与 raw NanoVG DPR 模式 B。
- 战场字体用项目自带 zpix。角色、核心、炮台使用已存在的图片/图集，敌人/弹道辅助标记使用可读中文，避免本地宿主缺少 Emoji 字体时显示空框。没有生成新图片或修改原图片。

“单房间加载”在本轮指表现与探索战斗内容的驻留，不是按房间下载资源包；全图轻量元数据仍保留。

## 开发环境核验

完整查阅了本地 editor-docs 的入口、架构、CLI、脚本指南、API 索引、Editor API、陷阱与示例说明，以及 Plugin 入口/架构/脚本指南，区分 EditorScript、玩法 Runtime、Maker-Plugin 与独立 Agent Session。按需查阅 `operate-editor` / `run-lua-validate`，没有将 Editor/ 或 Plugin.Agent 接进玩法。

`get_agent_workspace_state` 确认当前工程为 C:/Defense game，deployed=true、complete=true、missing=[]，四类客户端均部署 21 项 skill。编辑器当前为空场景且无未保存修改。MCP 通过 tools/editor_mcp.py 本机连接；受限 shell 不能发现连接，提升权限后成功。未改用户 MCP、编辑器场景、dev.json、UUID 映射或部署配置。

独立 Runtime 安装在 .cli。安装包缺少必需空 ResCache 目录及 UI 默认 MiSans，已只在 .cli/ResCache 补齐目录并复用编辑器自带字体；这是验证环境补齐，未修改引擎库或用户现有资源。

## 验证与边界

- 规则回归：145 PASS / 0 FAIL / 8 NOT_RUN；新增大网络、最近选择、廊道驻留和局部查询预算用例。历史 NOT_RUN 包含真人理解/留存等，仍未伪称完成。
- D1–D5 多组种子：真实走廊半径通行、回核路径、锁门、独立守军波、交易、传送与奖励去重均通过。
- 局部移动/视线 120 次：修复前 25 房 / 36751000 Lua 指令；修复后 97 房 / 552000 指令，减少约 98.5%。这是纯 Lua 工作量对照，不是手机 FPS。
- 真实 Windows GPU Runtime：菜单、战斗、最近布防、全场统计、大地图通过 JSON 报告；地图缩放和平移另有实际控件回调断言。80 怪压力样本无 Lua 错误、无缺失游戏资源。
- 一次 80 怪样本：update 平均约 3.9 ms / 最大 12 ms，render 提交平均约 3.6 ms / 最大 6 ms。只代表本机短时自动压力场景；不代表低端手机、长局、高波次或通关平衡。
- 自动截图实际为 1740×921，约 18:9，在要求区间内。CLI 请求的 1280×720 未被当前 Runtime 实际采用；截图名称记录请求参数，实际尺寸见日志和 PNG。尚无真实 16:9 与 20:9 双端窗口证据。
- 所有运行夹具位于 validation，临时 scripts/__room_runtime_qa.lua 在每次运行后删除，发布不会包含夹具。建造夹具仅在测试实例补充资金；未改正式初始资金、伤害或波次。
- 修改模块 LSP ERROR=0；全工程历史静态问题不纳入本轮无关重构。

证据：validation/defense/polygon-20261012/ 与 validation/defense/runtime-20261012/。
