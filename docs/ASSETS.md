## 三、素材引入优先级

### P0 - 强烈推荐（显著提升体验）

1. **音效组** — 使用星火 AI 生成 11 个核心音效
   - 零版权风险，即时可用
   - 覆盖射击/受击/升级/拾取等核心反馈
   
2. **背景音乐** — 使用星火 AI 生成 2-3 首 BGM
   - 标题轻松曲 + 战斗紧张曲
   - 填补游戏最大体验空缺

### P1 - 推荐（提升视觉品质）

3. **标题装饰字体** — 得意黑 或 站酷快乐体
   - 替换标题画面的 MiSans，增加视觉冲击力
   - SIL OFL / 免费商用，无版权风险

### P2 - 可选（锦上添花）

4. **技能图标字体** — iconfont 自定义图标包
   - 替换当前单字母技能图标（D/G/S/H/A...）
   - 需要手动在 iconfont.cn 挑选打包

5. **HUD 数字字体** — Pixelify Sans 等像素/等宽字体
   - 增强赛博朋克 HUD 风格
