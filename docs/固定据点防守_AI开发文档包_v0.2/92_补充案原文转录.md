## 补充案概览

涌现式底层设计与持续体验

补充策划案 V0.1

不是增加一次惊喜连招，而是建立能被玩家理解、复现、迁移的规则体系。

适用原案：固定据点防守_主玩法与地图设计策划案_v0.1。本文补充底层设计与体验标准，不覆盖原文，也不代表已修改游戏代码。

本轮确认与边界

| 类别 | 约束 / 目标 |
| --- | --- |
| 新增已确认要求 | 涌现式设计进入游戏底层；玩家须持续充分感受到，不是昙花一现。 |
| 继续保留 | 神殿模式主体、关卡内固定核心、Emoji 幸存者技术继承方向；剧情设定待定。 |
| 设计表达 | 同一套规则跨角色、敌人、设施与地图成立；不为每个技能组合编排特殊脚本。 |
| 玩家感受 | 我看懂了为什么发生 → 我能主动再做出来 → 换局势还能判断何时用或不用。 |
| 不等于已批准机制 | 击退、爆炸怪、减速参数、教学与指标是补充建议；需原型评审及原项目核验。 |

三个需要同时完成的目标

底层真实：交互来自统一属性、空间、时间与事件规则；没有规则之外的组合彩蛋来假装涌现。

当下可感知：玩家看得见对象特性、动作改变和实际结果，能把效果归因于自己的选择。

长期可应用：重复提供机会，但改变问题和取舍；熟练后有新情境，而不是重复同一个答案。

理论使用边界

MDA 将规则、动态行为与体验区分开；Juul 讨论规则组合形成的策略空间，并指出不能把任意规则交互都当成涌现。[1][2] 本文据此把“交互发生”和“玩家理解并运用”分开验收。

所有规则与数值均为本项目的原型建议；不以理论文章证明必然长期留存，不把尚未审读的技术能力写成已实现。

## 02 底层统一规则：先有协议，后有内容

对象不靠专用组合名关联

实体至少描述阵营、位置、碰撞、生命、重量、锚定状态、可减速状态、死亡反应和波次/据点身份。技能描述目标过滤、作用范围、伤害、位移、状态与触发条件。设施、敌人和角色读取同一套字段。字段是方案接口，不表示 Maker 已提供对应 API。

| 规则 | 全局约束 / 首轮建议 |
| --- | --- |
| R1 空间一致 | 碰撞、距离与遮挡用同一坐标系；击退沿施力方向，碰墙停止，不穿柱、不传送；墙与柱统一阻挡爆炸伤害。 |
| R2 锚定一致 | 核心与设施 anchored=true，技能不能位移；拒绝位移有清晰反馈，不能暗中移动防守点。 |
| R3 位移可控 | 首角色主动击退方向由角色到目标的相对站位决定，不强制增加手动瞄准摇杆。重量可影响位移量。 |
| R4 死亡反应 | explodes_on_death 在死亡位置延时 0.7 秒爆炸一次；可伤敌、玩家、核心与设施，提前标示范围。普通攻击不默认友伤。 |
| R5 时间一致 | 有效减速取最强、同源刷新时长、异源独立计时；首轮上限 50%，不无限相乘。技能冷却不因连锁自动重置。 |
| R6 因果一致 | 死亡、掉落、奖励和 wave_alive_count 各执行一次；原始动作 root_action_id 贯穿连锁，避免多层重复发奖。 |
| R7 身份一致 | 波次进攻怪与据点守军各自计数；跨系统伤害能杀死两者，但守军不计入清波。 |
| R8 状态一致 | 升级、暂停与关键演出暂停全部世界模拟；停止期间不偷偷推进伤害、生成、冷却或连锁。 |
| R9 感知一致 | 外观、标记与声音对应真实属性和结果；规则变更须明示，核心失败警报优先于连锁表现。 |

内容新增的接入门槛

新技能至少改变空间、时间、目标、资源或已有状态中的一项，并能与两个已有对象/系统自然互动。只加独立伤害百分比，不算新增交互维度。

评审写清：触发前提、结果、反例、玩家可见证据、策略代价；先画规则关系，再写技能名与包装。

首版不做六元素大全或复杂化学模拟；先验证击退—死亡反应与减速—范围—回防两组基础规则。

## 03 交互矩阵与策略空间

矩阵是检查规则覆盖的设计工具，不是列出七种隐藏配方。同一属性应在多种位置、敌人组合与资金状态下成立，玩家自行决定是否利用。

| 规则关系 | 产生的可选择结果 | 反例 / 代价 |
| --- | --- | --- |
| 位移 × 爆炸对象 × 怪群 | 改变爆炸位置，让死亡反应击中更多进攻怪。 | 推到核心边会伤核；墙体可能阻止推入目标区域。 |
| 位移 × 柱 / 通道 | 借障碍停止敌人推进，选择更安全的拦截点。 | 重装位移更短；没有足够回防距离时收益降低。 |
| 减速 × 范围攻击 | 敌人在区域停留更久，提高同时命中的机会。 | 怪群稀疏时不值；同类减速叠加不无限变强。 |
| 减速 × 回防 × 多路压力 | 用设施维持一条路线，为角色换路创造窗口。 | 另一条路突然增压，不能继续外出；设施无法替代全部守核。 |
| 死亡反应 × 建造位置 | 设施覆盖帮助引爆，也可能把危险爆炸留在核心附近。 | 布防不只是堆输出，需要控制爆炸发生的空间。 |
| 外圈奖励 × 建造 / 修复 | 探索资金换取防守能力，形成当前风险与后续收益取舍。 | 核心低耐久或错过战备时，继续探索可能直接失败。 |
| 成长选择 × 已有局势 | 同一控制/范围选项在不同怪群与路线下价值不同。 | 不保证每次选同一项最优；生存或修复也可能是合理答案。 |

至少三种可行解，而非三种皮肤

空间控制：以站位和击退决定哪里发生反应；收益来自几何与时机，不只是面板伤害。

时间控制：用减速与范围覆盖稳定一路，再切换角色去拦截另一条。

资源运营：更早拿据点资金或优先修复，换取更稳定的终局承受能力；不要求每局都外出。

检验是否只是一条万能连招

同一组合必须有适用情境与不适用情境。若所有入口、怪群和资金状态下都只需同一操作，则问题空间坍缩；优先调整路线压力、机会成本与反例，不频繁暗改已学会的物理规则。

## 04 场景 A：把爆炸位置变成玩家的选择

首版建议用“主动击退 × 爆炸推进怪 × 路线几何”建立空间控制。不是识别某个技能组合名才播放清场效果：任何原因导致爆炸对象死亡，都执行相同规则。

首轮测试参数：全部待原型验证

| 对象 | 建议参数 / 约束 |
| --- | --- |
| 主动击退 | 射程 4.5 格、位移约 3 格、冷却 8 秒；不附带伤害。选最近合法目标，并显示目标轮廓；站位决定施力方向。 |
| 爆炸推进怪 | 死亡后 0.7 秒、半径 2.5 格、伤害 40；同样伤及核心与设施。生命按首轮输出校准，能承受约 3–5 次初始命中。 |
| 位置与遮挡 | 爆炸中心锁定死亡点；结算时查当前存活目标、距离与墙柱遮挡。预警与命中使用同一范围，不做组合特例。 |

安全利用：同一张原案地图上的因果链

示例：角色 (16,21)，爆炸怪 (18,21)，两只普通怪约在 (22,20)/(22,22)，核心仍在 (32,21)。角色从西侧击退爆炸怪至约 (21,21)；路径无柱阻挡。随后击杀，引爆位置远离核心、覆盖两只普通怪。坐标是测试布置，不是要求每局刷同样位置。

| 步骤 | 实际状态改变 | 玩家看见什么 |
| --- | --- | --- |
| 站位与施力 | 最近合法目标被推向怪群。 | 目标轮廓、方向短线、真实位移。 |
| 击杀与预警 | 死亡位置锁定，加入延时事件。 | 0.7 秒危险圈；墙后区域不显示可命中。 |
| 反应与结算 | 实际覆盖目标受伤；死亡各结算一次。 | 简短因果线与实际命中数，不夸大清场。 |

危险情境：知道不引爆或先移走，也是掌握

爆炸怪在 (33,23) 时距离核心约 2.24 格，直接击杀会伤核。角色若在 (33,19)，可将其向南推至约 (33,26) 再处理；核心不移动。

被柱挡住、技能未冷却、目标选择不合适或回防太迟时，不能假装击退必成功。允许承受小损失、换站位或优先救另一条路线。

有效涌现证据：玩家主动改变站位/时机，得到不同结果，并能解释危险反例。单次自动攻击碰巧触发两次爆炸，只能算事件发生。

## 05 场景 B：用控制换窗口，但不保证总是划算

第二组建议用“减速 × 范围输出 × 换路/回防 × 资金”构成时间与资源决策。设施不是替玩家挂机，而是让玩家判断哪里能暂时交给设施，哪里必须亲自处理。

遵守原案经济，不凭空拥有两座塔

| 阶段 | 可行组合 | 必须付出的机会成本 |
| --- | --- | --- |
| 初始 60 资金 | 尚买不起 90 资金减速塔。先用角色能力守核。 | 不能为了展示组合偷偷赠送设施或抹掉价格。 |
| 资金达到 90 后 | 减速塔 + 已选择的角色范围升级。 | 放弃其他建造或留作修复的资金；未选范围升级仍可走空间控制路线。 |
| 资金达到 200 后 | 90 减速塔 + 110 范围塔，两个不同槽位。 | 占两个建造点；两塔配置不自动解决三路压力。 |

南路覆盖：规则产生窗口，玩家决定怎样利用

示例在 T3=(27,28) 建减速塔；建议范围 5.5 格、基础减速 35%、状态持续 2 秒，离开范围不再刷新。南路 x≈32 的部分路段被覆盖。范围显示依据实际距离与可作用目标，不能把整条南路画成安全区。

密集普通怪停留在范围输出区更久，角色可以先清密集波，再去另一条入口；减速只是增加可操作空间，不承诺固定多出多少秒。

战备时可考虑近层据点；战斗期开启后回城禁用。外出前看真实残敌、到核距离、塔状态与下一波预警，设施被破坏时及时回防。

减速状态结束、重装推进、远射骚扰或另一条路增压，都可能让继续探索不划算。稀疏单体或 Boss 情境可能更适合单体输出、修复或保留技能。

资源反例：同一个组合不应是万能答案

例：战备资金 120、核心缺损 200。买减速塔 90 后余 30，不够支付 40 修复；先修复后余 80，又暂时买不起减速塔。买范围塔 110 则只余 10。选择由下一波入口、已有输出和承伤能力决定，而不是固定“先控制塔”。

应展示的反馈与不应伪造的反馈

展示减速图标、范围边界、命中事件、到手资金与实际修复量；阶段复盘可列“减速覆盖目标、同区范围命中、资金支出”。不自动宣布“你因此避免了 300 核心伤害”或“争取了 8 秒”——没有可验证反事实，就不生成此类因果战报。

## 07 让发现成为成长：本局机会与教学节奏

教学教观察与判断，不直接替玩家完成连锁。原案 20 波、入口次序、关键敌人和总量保持基线；下表只建议在普通怪名额内替换子类型、调整批次位置与候选机会。

| 波段 | 给玩家的真实机会 | 提示与验收重点 |
| --- | --- | --- |
| W1–3：看懂对象 | 先看击退与受控推进；W3 可将 1 个普通怪名额换成爆炸推进怪，在远离核心的位置提供可观察机会。 | 仅解释外观与危险圈。玩家能够指出“它在哪死，就在哪爆”。 |
| W4–5：第一次发现 | 双路到单路切换；至少两次独立空间控制机会。W3–5 至少提供一次范围成长候选，不强制玩家选择。 | 失败或错过后可选一句提示；不自动推怪、不脚本清场。 |
| W6–10：无提示再现 | 击退路径、密集批次和可负担的减速建设重复出现；保留精英及 W10 东路 Boss。 | 关闭配方指令，看玩家能否自己换站位、再做一次；未买塔仍有其他解。 |
| W11–15：情境迁移 | 三路压力、柱旁路线、资金缺口或设施受损；保留 W15 南路 Boss。 | 只提示局势，观察玩家能否将规则用在不同入口，或有理由地不用。 |
| W16–20：作出取舍 | 错峰、混合阵容、近核危险对象和修复需求；保留 W20 终局 Boss 与残敌清理。 | 不增加隐藏规则。检验技能保留、先后顺序与核心安全，而非连锁次数越多越好。 |

保底的是交互机会，不是胜利结果

首原型用自带主动击退的单角色，保证第一组关系可以主动操作。以后每个起始套装至少连接一组既有交互，不把涌现全押在罕见掉落。

成长候选可做机会保护，但不能赠送玩家未选的能力；资金不足、错过窗口或主动放弃时，保持其他可行路线，不暗改经济。

同一规则至少给出安全利用、危险反例和不同位置三类情境。随机性改变条件，不随机改变碰撞、友伤或死亡触发规则。

不给新手一次性讲完所有配方

首次只显示对象特性与一条观察提示；理解后收起提示，把信息留在常驻图标和可回看的规则卡中。规则卡写“爆炸也会伤核”等通用因果，不列“按此三步必胜”。试验空间要容许一次可恢复错误，不通过隐藏免伤假装安全。

<a id="e08"></a>
## 08 让玩家归因于自己：界面、声音与复盘

反馈目标是“看见我的选择改变了局势”，不是只看见满屏特效。视觉、声音与战报必须读取真实交互事件；事件发生不能自动等同于玩家有意设计。

| 时间 | 必要反馈 | 避免的误导 |
| --- | --- | --- |
| 动作之前 | 爆炸对象的形状/图标、减速与锚定标记；击退目标轮廓、冷却、合法范围和危险对象靠核警报。 | 只靠颜色辨识；没有依据的“安全”标签；隐藏友伤。 |
| 动作发生 | 短方向线、实际位移、受控动作与状态图标；锚定对象明确提示“固定，不能推动”。 | 位移失败也播放成功动画；夸张镜头让玩家看丢核心。 |
| 反应发生 | 真实爆炸预警与遮挡，减速进出边界；将动作、反应、命中分层显示，关键声音可区分。 | 满屏粒子遮住弹道；同音效混淆敌人爆炸与核心受击。 |
| 实际结果 | 命中/击杀数量、对象生命变化、真实资金与修复结果；最多一条短因果提示。 | 编造节约时间、避免伤害或“完美策略”评价。 |
| 阶段与局末 | 选 1–2 条真实事件链，标明来源、位置、目标和实际后果；允许展开或关闭。 | 每次连锁都弹教学；只放胜利烟花，没有因果信息。 |

信息优先级与无障碍要求

核心危险 > 敌方关键攻击预警 > 玩家因果反馈 > 掉落与庆祝。核心血条、入口箭头和技能冷却不因连锁提示消失。

属性至少用图标/轮廓加文字辅助，不只用红绿；音效可调，镜头震动与粒子可减弱。弱化特效不影响机制结果。

连锁摘要建议停留 1–2 秒、合并同根事件；普通战斗不强制慢动作。关键演出或升级若暂停，全部事件与计时同步冻结。

动态漫的正确作用：强化经历，不代替玩法

阶段/局末可按真实事件标记选择短镜头模块，例如核心受损或成功远距离处理危险对象。镜头、人物表情、声音应回应已发生的事实；具体角色与剧情仍待定。首次发现不强制插入长片段，重试支持短版/跳过，战斗中不遮挡预警。

战报示例：“击退改变爆炸位置 → 爆炸命中 3 个敌人，核心受到 40 伤害”。仅在日志确实如此时显示；既呈现收益也呈现代价，不把预制演出冒充玩家自主创造。

<a id="e09"></a>
## 09 不昙花一现：跨局改变问题，保留学会的规则

建议把可持续体验设计为：规则保持稳定，新的局势需要新的判断。不是每局不断塞入新元素，也不是用更高血量逼玩家刷数值。是否形成长期兴趣仍须重复游玩验证。

| 可变化的条件 | 怎样形成新的决策 | 不变的底线 |
| --- | --- | --- |
| 批次与入口压力 | 同一路密集或两路错峰，改变技能何时用、角色先去哪。 | 首版保留原案入口序列、波数与总量；核心不移位。 |
| 敌人组合 | 爆炸对象处于队首/队尾，夹杂远射或重装；控制价值随局势改变。 | 属性可见，死亡与友伤规则不暗改；重装等新增类型另审。 |
| 预算与受损状态 | 据点收益、当前生命与修复需求，改变下一份资金用途。 | 价格、限制和奖励来源明确，不靠随机罚没资金制造变化。 |
| 成长与设施 | 在覆盖、控制、单体和生存间选择；同一构筑也需要换操作。 | 保留至少一条可操作交互路径，拒绝唯一高效配方。 |
| 章节路线几何 | 后续地图可改变拐点、间距与建造点，让已有理解再迁移。 | 先做当前固定地图；新地图单独立项，核心仍在关内固定。 |

内容导演与随机性的边界

将波次配置标注为密集窗口、双路取舍、近核危险、资金紧张等情境；同一局分布多个机会。标签安排问题，不按玩家刚按键就刷完美目标。

限定压力预算、关键预警和可达路线；不要把爆炸、精英、多路增压与强制演出无约束叠满。若全部情境一个答案就解决，优先修正条件与成本。

横向成长和可回忆的策略经历

跨局奖励优先解锁不同控制方式、起始套装与章节挑战，不把规则理解藏在付费/长时间刷取后。解锁内容必须接入既有关系，并带来新的适用情境与代价；永久数值成长不作为本补充的默认前提。

局末给玩家带走一个问题，例如“同样的爆炸，如果发生在东柱旁还能这样用吗？”规则卡与真实战报可回看。重复游玩应从照做教程变成主动规划；有理由地减少连锁、保技能或放弃探索，同样值得肯定。

反昙花一现标准：见过之后仍愿意尝试；没有提示仍会复现；换局势仍能判断；熟悉一组关系后，不会只剩无脑重复。

<a id="e10"></a>
## 10 技术护栏：真实交互、可靠结算、可承受性能

以下是与引擎无关的接口要求，不是对 Emoji 幸存者或 Maker 现有能力的断言。先核验项目结构，再决定复用、扩展或新增；不要同时重写已能稳定工作的输入与成长模块。

| 协议 | 最小字段 / 约束 |
| --- | --- |
| 实体 | entity_id、team、position、collision、hp、weight、anchored、可受状态、death_reaction、wave_id / room_id；死亡有唯一已提交标记。 |
| 效果 | 目标过滤、距离、遮挡政策、伤害、位移、状态来源与期限、触发条件；效果读取公共空间和状态接口。 |
| 因果事件 | event_id、parent_event_id、root_action_id、source/target_id、计划时间、实际位置、前后状态、命中/失败原因。 |
| 事件排序 | 按计划模拟时间与稳定序号处理；死亡反应排队，不递归直接调用下一次死亡。暂停同时冻结模拟时钟与队列。 |
| 结算身份 | 死亡、掉落、奖励与清波计数分别去重；据点守军不增减波次计数；统计不按链条层数再发奖。 |

一次效果如何变成可追踪的结果

合法性过滤 → 空间/遮挡查询 → 提交位移与状态 → 提交伤害 → 提交死亡 → 安排反应及一次性结算 → 更新波次/据点 → 同时间槽胜负裁决 → 发送真实反馈。同一效果包先位移后伤害，死亡位置读取提交后坐标；不同效果按稳定序号处理。

当进攻怪归零但本波还有待结算的有害反应，如尸爆，不提前切战备或判终局胜利。角色/核心死亡失败优先；不得用胜利动画取消已经触发的危险。

首版只开放一次性死亡反应与有期限状态，不引入“击中再发同源攻击”“反应重置冷却”的无限闭环。新触发类型先审查循环与合法边界。

性能不能以悄悄砍掉规则来换

用空间索引查局部候选、复用碰撞查询与表现对象；沿用原案生成软上限建议 80，超限延后批次，不删除活怪、不提前清波。

每个爆炸对象只能死亡并反应一次，首版不在死亡时无限生成新爆炸对象。先做最坏情境压测，再决定场景与批次预算。

不静默截断连锁层数或只处理前 N 个目标。性能紧张先减粒子/合并音效/限制后续生成；核心伤害、状态与结算保持完整。

验收须覆盖：连锁中打开升级、暂停/失焦、跳过演出、恢复与退出重试。恢复后顺序和时钟连续，没有补发两次爆炸、漏掉一次掉落或演出期间继续伤核。

<a id="e11"></a>
## 11 验证玩家真正掌握，而非只统计特效

把“系统发生了什么”和“玩家知道自己在做什么”分开。日志提供可核对事实，观察与访谈判断理解/意图；不能仅凭连续两次按技能，就宣称玩家掌握了涌现。

| 层级 | 判定证据 | 记录与分母 |
| --- | --- | --- |
| 机会覆盖 | 在可操作距离内，有可观察的交互对象与安全尝试空间。 | 符合条件的窗口次数；覆盖到的到达 W5 受试者 / 全部到达者。 |
| 发生与发现 | 日志证实交互；玩家能用自己的话说出至少一个真实因果。 | 事件发生单独统计；理解人数 / 见过有效机会人数。 |
| 主动复现 | 不同时间窗口，无配方提示主动调整位置/时机并再现；能解释目的。 | 复现人数 / 已理解且再次获得机会人数；错误尝试也记录。 |
| 迁移与取舍 | 新入口、遮挡、资源或近核危险下合理使用，或解释为何不用。 | 通过新情境人数 / 参加该情境测试人数；并记录到达率。 |
| 持续兴趣 | 第 2–3 局仍提出新尝试，有不同选择，不只是背同一操作。 | 观察策略变化、主观意愿与退出原因；不能替代正式留存测试。 |

临时原型目标：不是行业基准或留存承诺

建议机会覆盖 ≥90%；到 W5 能解释一次因果 ≥70%；已理解且再次获得机会者中，无提示主动复现 ≥60%；第 2–3 局参加新情境者中，迁移或解释合理不用 ≥50%。须同时公布分子、分母、到达率和提示使用，避免筛掉失败者后虚高。

两轮测试：先修看不懂，再测是否只剩一个答案

第一轮建议 6–8 名新手、每人约 10 分钟的定点场景：先不教配方，结束后问“刚才为何发生”“怎样再做”“什么时候不该做”；据反馈调整可读性。

第二轮建议 12–16 人各玩 2–3 局：第一局允许最小属性提示，后续不指挥操作，并换一个路线/预算情境。记录熟练后是否仍有判断、重复失败点与退出原因。

四种“昙花一现”的诊断

| 现象 | 优先修正 |
| --- | --- |
| 发生很多却解释不了 | 补前提信号、动作到结果的因果反馈，不先堆新内容。 |
| 看懂却不能再做 | 检查机会过稀、目标选择/站位不可控、早期死亡太快。 |
| 复现后只会万能连招 | 补危险反例、资源成本和路线压力，保持规则稳定。 |
| 每次都需提示或罕见掉落 | 把交互入口放进起始套装与正常波次，逐步撤掉指令。 |

默认用本地匿名试玩编号及最小事件日志，不采集真实账号或无关身份信息。小样本只用于发现设计问题；长期留存须另设周期、对照与足够样本。

## 12 落地顺序、验收清单与原案衔接

| 阶段 | 实际交付 | 通过后再做下一步 |
| --- | --- | --- |
| A：底层真实 | 共同实体/效果协议、事件队列；先完成击退、爆炸、锚定与遮挡。 | 同一规则跨敌人、角色和核心成立，结算不重复。 |
| B：玩家看懂 | 减速与范围接入；对象提示、真实预警、短因果反馈和两组定点场景。 | 无配方指挥，也能解释并主动复现一次。 |
| C：持续应用 | 接入原 20 波机会表、经济取舍、迁移反例与事件复盘。 | 换情境需要判断，不是一招处理所有问题。 |
| D：拓展与包装 | 压测后扩展套装/章节；按真实事实接动态漫镜头模块。 | 新内容接现有规则，演出不遮危险、不伪造结果。 |

首版完成门槛

核心/设施始终固定；推向柱、墙或非法区域会停止；爆炸遮挡、友伤与危险圈前后一致。

敌人、角色、设施造成的同类死亡都走同一反应；每次死亡只掉落/奖励一次，守军与波次计数不混用。

连锁中暂停、升级、演出跳过与恢复不漏结算；最后敌人死亡仍等待危险反应，同时间槽核心死亡优先失败。

资金 60 买不起 90/110 的设施；120 资金不能同时买 90 的塔与 40 修复；示范组合遵守真实价格。

至少两组交互各有可用情境、反例和迁移情境；玩家可以不选某成长项、放弃探索或不用连锁仍有合理解。

代表性新手可无提示复现；连续 2–3 局观察仍有新的取舍。只达到事件触发数量，不算完成玩家体验验收。

与原案的关系与待确认项

保留原案固定核心 (32,21)、三路入口、四建造点、20 波基线、15 秒战备与 8 秒预警、建造/修复价格。爆炸怪只替换普通怪名额；击退、友伤爆炸、状态规则、机会保护与复盘均须评审，不擅自改写原文。

待审读技术遗产：索敌与攻击入口、统一受伤/死亡、技能冷却、设施与核心目标、暂停时钟、掉落去重、空间查询、波次身份及可用性能。剧情设定继续留白；本文件是设计规范，不是游戏代码完成报告。
