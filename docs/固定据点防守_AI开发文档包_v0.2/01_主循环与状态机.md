# 主循环与状态机

## 三层循环

秒级循环：方向判断 → 移动拦截或回防 → 攻击技能 → 拾取 → 升级判定 → 清波检查。波次循环：战备探索 → 满足方向预警 → 配置生成 → 战斗清空 → 发放本波奖励 → 下一波或终局。章节循环：选择角色与方案 → 开场 → 部署守核 → 胜负结算 → 保留奖励与解锁 → 调整方案重试。

## 状态表

英文标识是 E 命名建议，实际代码可复用已有命名。

| 状态 | 进入行为 | 退出条件与去向 |
| --- | --- | --- |
| DEPLOY 入场部署 | 重置核心、角色、起始技能、资金 60 和地图 | 开场结束或跳过 → PREPARATION |
| PREPARATION 战备探索 | 15 秒游戏时间，允许后勤与探索，末 8 秒方向预告 | 时间到或主动开波 → 补足预警或直接 ATTACK |
| WARNING 开波预警 | 仅补足尚缺的方向提示时间 | 累计达到 8 秒 → ATTACK |
| ATTACK 波次进攻 | 执行本波生成队列，战斗、拾取、升级，允许风险探索 | 队列完成、本波存活数为 0、本波待结算有害反应处理完 → WAVE_SETTLEMENT |
| UPGRADE_CHOICE 升级选择 | 暂停世界，给出 3 个合法且不重复选项 | 选择后返回进入前状态，溢出经验可再次选择 |
| WAVE_SETTLEMENT 本波结算 | 本波奖励只发一次，检查存活与终局 | 非终局 → 下一波战备；终局符合条件 → 胜利 |
| END_SETTLEMENT 结束结算 | 停止生成、伤害、拾取，保留已结算局外奖励 | 返回章节选择或新局重试 |

开场和终局演出可以作为独立流程或暂停覆盖层，原文没有规定内部状态结构。采用 E 实现时与 [08](08_剧情演出与接入.md) 对接，并先解决 Q10 的部署顺序差异。

## R01 战备与预警

战备采用可暂停的游戏时间。自然开波时，t=7 秒开始预告，t=15 秒已展示 8 秒，所以无需再串行等待 8 秒。主动开波时按已展示的有效游戏时间补足预警。

| 例子 | 已展示预警 | 离开战备后的补足 |
| --- | --- | --- |
| 入战备立即开波 | 0 秒 | 8 秒 |
| 战备第 10 秒开波 | 3 秒 | 5 秒 |
| 战备倒计时正常结束 | 8 秒 | 0 秒 |

以上算例为 D 推导。补足 WARNING 阶段是否仍能后勤或探索见 Q08，不能自动延续战备交易权限。进入 ATTACK 前生成队列启动一次。终局演出结束后方向提示仍须足够；提示是否重置见 Q10。

## R02 胜负和清波

胜利同时满足：第 20 波生成结束、当前波进攻怪存活数为 0、本波待结算有害反应全部处理完、角色生命 > 0、核心耐久 > 0。任意局内状态角色生命 ≤ 0 或核心耐久 ≤ 0 立即失败。失败优先于同帧 Boss 死亡或胜利条件；结局只能确定一次。

进攻怪归零后，若本波仍有尸爆等待结算的有害反应，保持战斗状态，继续处理其队列；反应可导致新死亡与下一次合法反应，因此重新检查直到没有待结算危险。禁止先进入战备或播放胜利动画来取消既有危险。同时间槽先处理确定的结果，再判角色/核心失败，最后判清波和胜利。反应归属与据点衍生事件的门槛见 Q19；单纯据点守军存活仍不计清波。

清波计数只包含当前 wave_id 的进攻怪和 Boss 已生成召唤物。外圈守军不计入。Boss 死亡停止后续召唤，已生成召唤物仍须清理。达到软上限而延期的批次意味着生成尚未完成。

P 补充方案规定因果事件按计划模拟时间与稳定序号处理，同一效果包先位移后伤害，死亡反应排队；同时间槽结果提交后先判失败，再检查清波及结算。E 实现建议：由统一事件入口执行该顺序，见 [09](09_数据模型与模块契约.md)。保证不会先发胜利奖励再改判失败；非胜利清波奖励与同帧失败的关系仍见 Q11。

## R03 暂停与恢复

| 触发源 | 冻结内容 | 恢复位置 |
| --- | --- | --- |
| 升级三选一 | 怪物、弹体、伤害、生成队列、战备计时、技能冷却 | 原状态与原波次 |
| 战备后勤菜单 | 世界与剩余战备时间；合法操作即时扣款 | 关闭菜单恢复剩余战备 |
| 单人暂停或失焦 | 全部模拟 | 显示当前波和方向后恢复 |
| 关键剧情停顿 | 战备、生成、伤害、弹体、冷却 | 演出定义的节点与完整预警 |

E 实现建议：统一模拟时钟并采用暂停原因集合，只有全部原因解除才恢复；UI 选择和菜单关闭交互持续可用。防止关闭一个面板意外解除另一暂停原因。补充方案要求因果队列、尸爆 0.7 秒延迟、有期限减速和所有连锁计时同样冻结；恢复后按原计划时间与稳定序号继续，既不漏结算也不重放已提交事件。回城引导与敌人重寻路计时也按模拟时间冻结，属于一致性建议。

## R04 奖励与新局

本波奖励发放一次；每完成 5 波记录阶段奖励；首次完整通关解锁下一章节。原型结束时停止生成、伤害和拾取。失败不默认复活，也没有付费续命。

退出或重试时隔离旧局事件，旧队列不得作用于新局；这是 E 生命周期建议。失败终止后停止新的战斗副作用，保留已经提交的局外记录。

新局重置局内经验、等级、技能构筑、资金、设施、核心与角色状态、据点和已领取据点奖励；保留已结算局外记录。剧情 seen 的局内/局外分层和回看语义由 Q10 决定，不可随意一起清空。

验收入口：V01、V02、V03、V04、V05、V06、V07、V19。完整样板仍以 20 波为候选；阶段 A 的 5 波胜利仅为显式测试配置，见 [11](11_开发阶段与任务.md)。

原图的清波文字是主案历史表达，当前实现以 R02 的有害反应等待为准。新增验收 V24、V25、V27，原 V01/V07 同步扩展；相关协议任务为 T15、T16。
