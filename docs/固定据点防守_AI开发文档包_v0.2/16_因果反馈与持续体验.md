## R39 真实因果反馈

所有视觉、声音、战报从真实属性与已提交事件读取。反馈解释结果，不制造结果；连锁发生不自动说明玩家有意设计。

| 时点 | 显示内容 | 完成判断 |
| --- | --- | --- |
| 动作前 | 危险对象形状/图标、减速/锚定属性、合法目标轮廓、冷却、范围、近核警报 | 玩家可辨属性与风险；非只靠红绿颜色，无无依据安全标记 |
| 动作时 | 方向短线、实际位移、受控动作与状态；锚定拒绝说明 | 成功失败对应真实状态，不假成功，不用夸张镜头让人看丢核心 |
| 反应时 | 爆炸预警和遮挡、减速进出、动作/反应/命中分层、可辨声音 | 圈与命中一致，核心受击可与爆炸区分，不遮弹道 |
| 结果时 | 命中/击杀、生命变化、到账和修复量，最多一短因果提示 | 无编造避免伤害、节省秒数或完美策略 |
| 阶段/局末 | 1–2 条真实链，来源/位置/目标/后果，可展开关闭 | 不每次弹教学；既显示收益也显示代价 |

信息顺序：核心危险 > 敌方关键预警 > 玩家因果反馈 > 掉落庆祝。核心条、入口箭头、冷却不因摘要消失。属性图标/轮廓加文字辅助，音效可调、震动与粒子可减弱；表现降级不影响逻辑。

同 root_action_id 合并连锁摘要，建议 1–2 秒；普通战斗不强制慢动作。关键演出或升级暂停时，事件与模拟时间同时冻结。展示“击退改变爆炸位置 → 命中 3 个敌人，核心受到 40 伤害”只在日志真如此时显示，不能把示例数字写成固定模板结果。

动态漫可在阶段/局末由真实事实标记选择短镜头模块；具体角色/剧情待定，首次发现不强制长片段，重试短版/跳过，镜头不遮敌方预警。回看无玩法副作用。

## R40 规则稳定与持续应用

本局闭环为观察 → 猜想 → 试验 → 理解 → 主动再现 → 新局势迁移。第一次只介绍对象特性和一条观察提示；理解后收起提示，以常驻图标和可回看的规则卡承载通用因果。教学不直接替玩家推怪或清场。

规则卡示例是“在哪死亡就在哪爆炸”“爆炸也伤核心”“墙柱阻挡爆炸”，不提供三步必胜配方。安全尝试容许可恢复错误，通过真实规则给空间，不能隐藏免伤。

| 可变化条件 | 形成的新判断 | 保留底线 |
| --- | --- | --- |
| 批次/入口压力 | 密集或错峰改变技能时机与先去方向 | 首版入口序列、波数、总量与核心固定不变 |
| 敌人组合 | 爆炸队首/队尾、远射/重量改变控制价值 | 属性可见，友伤/死亡规则不暗改；新重装另审 |
| 预算与受损 | 据点资金、耐久、修复改变支出 | 真实价格、限制与来源，不随机罚没 |
| 成长和设施 | 范围/控制/单体/生存选择，同构筑换操作 | 至少一条可操作交互路径，不唯一高效配方 |
| 后续地图几何 | 拐点/间距/槽位促进迁移 | 当前图先完成，新地图单立项，关内核心仍固定 |

内容导演可标密集窗口、双路取舍、近核危险、资金紧张等问题，不在按键后临时刷适配答案。压力预算限制爆炸/精英/多路增压与强制演出叠满，保留预警和可达路线。

跨局奖励优先候选为不同控制方式、起始套装和章节挑战。解锁接现有关系并有新适用情境与代价，不把理解藏在付费/长刷后，也不默认永久数值。局末可留下“东柱旁同样爆炸还能这样用吗”等问题，规则卡与事实战报回看。

玩家有理由减少连锁、保技能或放弃探索同样可以证明掌握。反昙花一现要求：见过仍想试、没提示能复现、换局势能判断、熟悉后仍有新取舍。是否形成长期兴趣仍需 [17](17_涌现体验试玩验证.md)重复游玩检验，不能从系统设计直接推出留存。
