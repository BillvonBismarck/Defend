# 涌现体验试玩验证

来源：[补充案第十一节](92_补充案原文转录.md#e11)。玩法日志核对机制，观察和访谈核对理解与意图。人数、时长与百分比是 P 临时原型建议，非行业基准或长期留存承诺；测试安排仍需 Q21。当前仅提供方案，未招募或进行试玩。

## R41 体验证据与试玩流程

| 层级 | 有效证据 | 记录与分母 |
| --- | --- | --- |
| 机会覆盖 | 可操作距离内的可观察对象和安全尝试空间 | 合格窗口次数；覆盖的 W5 到达者 / 全部 W5 到达者 |
| 发生/发现 | 日志确证交互；玩家自己的话解释一个真实因果 | 发生单列；理解人数 / 见过有效机会人数，W5 节点记录 |
| 主动复现 | 不同时间窗口，无配方提示，主动改变位置/时机并说明目的 | 复现人数 / 已理解且再次获机会人数；错误尝试同录 |
| 迁移/取舍 | 新入口/遮挡/预算/近核危险下合理用，或说明不用 | 通过人数 / 参加该情境测试人数，并报告到达率 |
| 持续兴趣 | 第 2–3 局仍提出新尝试、有不同选择 | 策略变化、主观意愿、退出原因；不是正式留存 |

临时目标：机会覆盖 ≥90%；到 W5 能解释一次因果 ≥70%；已理解且再次获机会者无提示复现 ≥60%；第 2–3 局参加新情境者迁移或合理不用 ≥50%。解释率的 W5 观察范围与“见过有效机会”分母需按 Q21 预先规定，并同时报告所有 W5 到达者；不能测试后剔除失败者抬高比例。

每项同时公布分子、分母、到达率和提示使用，报告死亡/退出/缺机会人数及原因。指标未达到就诊断规则或反馈，不只补特效。即使达到临时百分比，也只能支持该样本原型结果。

## 第一轮 定点可读性

建议 6–8 名新手，每人约 10 分钟，使用两组定点场景。先不教配方，保留属性线索。结束问：“刚才为何发生”“怎样再做”“什么时候不该做”。观察目标选择、站位、危险圈和核心损失归因；用日志核对回答，修可读性后再扩大内容。

## 第二轮 连续2至3局

建议 12–16 人，每人 2–3 局。第一局允许最小属性提示，后续不指挥操作，换路线或预算情境。记录主动计划、无提示复现、合理不用、重复失败和退出原因。机制与规则保持不变，变化的是问题条件。

需要有人类真实试玩和观察；自动操作可以验证队列/目标，不支持玩家理解结论。若实际人数不足、未进行第二轮、提示未撤或新情境未到达，明确写未验证，不用模拟人数填表。

## E 最小日志与观察记录

本地匿名试玩编号，默认不采真实账号或无关身份信息。保留最小事实链：试玩编号、局序、配置/规则版本、场景与波次、提示状态、有效机会、玩家动作、root/parent 事件、实际位置/目标/结果、核心变化、退出原因。观察另记原话、目的、是否主动、是否迁移或合理不用，不能由技能按两次自动推断。

原始日志与观察表相互引用，每项体验判断能找到事实与玩家解释；保存格式与保留期限见 Q21。这是记录建议，不要求远程分析平台或上线账号采集。

## 诊断与修正顺序

| 现象 | 优先修正 |
| --- | --- |
| 发生很多却解释不了 | 前提信号、动作到结果的真实因果反馈 |
| 看懂却不能再做 | 机会过稀、选目标/站位不可控、过早死亡 |
| 复现后只剩万能连招 | 危险反例、资源成本、路线压力，保持规则稳定 |
| 每次需提示或罕见掉落 | 起始套装与正常波次给可操作入口，逐步撤指令 |

正式长期留存另需时间周期、对照与足够样本，不在本次小样本方案中宣称验证。T20 第一轮和 T22 第二轮分别交付事实报告、问题诊断与修订证据；若未实际进行，列计划或未执行状态。验收 V32–V34。
