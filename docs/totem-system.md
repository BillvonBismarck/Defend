- **获取方式**：击杀 Boss 掉落
- **背包上限**：600 个
- **装备上限**：3 个

## 玩家数值计算公式

图腾装备后通过 `Player.RecalcStats()` 影响玩家属性。

### 基础属性（HP / ATK / SPD）

图腾固定值加入基础属性，**享受升级成长 + 百分比放大**：

```
生命 = floor( (基础HP × 角色倍率 + 图腾HP固定值) × (1 + HP成长 × (等级-1))
              × (1 + 技能HP% + 遗物HP% + 图腾HP%) )

攻击 = floor( (基础ATK × 角色倍率 + 图腾ATK固定值) × (1 + ATK成长 × (等级-1))
              × (1 + 技能ATK% + 遗物ATK% + 图腾ATK%) )

速度 = (基础SPD × 角色倍率 + 图腾SPD固定值)
       × (1 + 技能SPD% + 遗物SPD% + 图腾SPD%)
```

> 图腾固定值越早装备，随等级成长收益越大。例如罕见攻击图腾 +30，在 10 级时实际贡献远超 30。

### 暴击率

最终加算，不乘基础：

```
暴击率 = 基础暴击 × 角色倍率 + 暴击成长 × (等级-1)
         + 技能暴击% + 遗物暴击% + 图腾暴击%
```

> 暴击率超过 100% 时，溢出部分按 2 倍转化为暴击伤害倍率加成。
> 例：暴击率 130% → 实际暴击率 100%，暴击伤害倍率额外 +0.6（溢出 30% × 2）。

### 攻击间隔

```
攻击间隔 = 基础间隔 × (1 - 技能攻速% - 遗物攻速% - 图腾攻速%)
           下限 0.1 秒
```

### 伤害结算

```
基础伤害 = 攻击力
暴击判定 → if random() < 暴击率 then 伤害 × (暴击倍率 + 图腾暴击伤害%)
```

### 加成来源映射

| 来源 | 数据位置 | 作用方式 |
|------|---------|---------|
| 图腾固定值 (hp/atk/spd) | `VALUE_TABLE[稀有度][类型]` | 加入基础属性，享受升级成长 |
| 图腾百分比 (crit/fire_rate/hp_regen/loot) | `VALUE_TABLE` 值 ÷ 100 | 最终加算 |
| Boss 图腾百分比 | `BOSS_TOTEM_BONUSES[typeId]` | hpBonus / atkBonus 等乘算，罕见×2 |

## 合成系统

**规则**：3 个同稀有度图腾 → 1 个新图腾

| 结果 | 概率 |
|------|------|
| 升一级稀有度 | 30% |
| 保持原稀有度 | 50% |
| 降一级稀有度 | 20% |

- 垃圾级不会降级（已是最低）
- 罕见级不可合成（已是最高）

## ID 保底机制

| 查询函数 | 用途 | 保底值 |
|---------|------|--------|
| `GetTypeById(numId)` | 数字ID → typeId | `"hp"` |
| `GetTypeNumId(typeId)` | typeId → 数字ID | `1` |
| `ValidateTypeId(typeId)` | 校验有效性 | `"hp"` |

存档中若存在已删除的图腾类型，反查时自动回退为 hp（生命图腾），避免存档损坏。
