# 房间复用与考验波次

依据 U04。将原有探索房间转化为后续防守节点，构筑和远征共同消费其空间。具体波点和规模为 P，见 [08](08_原型决策与待定事项.md)。

## R01 独立生命周期

保留原探索状态 unvisited → active → cleared → claimed；reward_claimed 继续表示本局一次性金币/经验领取。模块获取跟随首次领奖事务，见 [01 B02](01_防守构筑系统.md#b02-获取安装与资金)。

新增防守状态由条件推导：未清不可部署；已清且有合法槽位可部署；设施存在时已布防；考验经过时交战；考验结束后设施保留。该状态不覆盖探索状态，也不把已清房间重置为 unvisited。

P 已清但尚未领奖即可建造，与现有“清空即可解锁”的逻辑一致。解锁模块仍要求首次领奖。考验门开放和敌人经过不改变探索状态、守军清空或奖励记录。

## R02 部署权限与设施寿命

P 主殿四槽保留；三房间样板每房间新增一个外围固定槽，扩展地图按职责配置外围槽。全局存活设施上限独立于槽位数，默认值见 08；主殿与外围共用上限与资金。

建造条件：战备且后勤已打开、房间已清、槽位合法且为空、资金足够、存活设施未达上限。主体权限由 Economy 重验。P 后勤面板能选择已清房间槽位，首原型不追加玩家必须站在槽边的交互门槛。

主殿设施持续运行。外围设施 P 只在所属区域有考验目标时攻击，普通主殿波次不自动激活未探索守军；生命和冷却保留。区域范围由配置矩形/多边形查询，不复用敌人的守军 room_id。

塔受损、摧毁、重建、升级、拆除和模块遵守同一经济协议。摧毁后释放存活上限，槽位不消失；模块来自本局库存而非被摧毁塔，不因重建重复获得模块。每房间限伤影响对主敌的实际输出，塔本身耐久不受该限伤。

## R03 考验组织

将考验定义为波次上的 challenge 配置，而非第二套运行循环：

1. 战备提示考验的路线、目标房间及玩家现有布防；允许修改设施和主动开波。
2. 预警服从现有剩余预警补足，门开放与路径校验一次执行。
3. 攻击期按普通队列及特殊队列生成。三房间样板在第5波加入一只远征主敌；原正式 20 波配置作为独立基线保留。
4. 普通怪继续守核压力；主敌沿路线经过房间，外围塔与角色拦截。没有清房或布防也可以选择主要回核，不生成强制探索任务。
5. 只有全部普通/特殊进攻实体及有害反应合法结算后，才进行清波、阶段记录或胜利。

扩展地图的中段考验和第20波终局采用显式配置，默认安排见 08。正式原型的额外单位数量应独立计数，原基线 1176 的校验只用于 legacy_v02。

## R04 房间复用的反馈与收益

雷达与房间面板显示可部署、已部署、敌人下一站、当前交战和该站有效输出。复盘同时显示建设/模块支出、角色与设施实际伤害、主敌带入终局的剩余生命和核心损失。

P 复用本身不再次发房间金币/经验；特殊敌人死亡奖励走敌人唯一死亡结算。路线经过、预算耗尽、退出房间和开启门均不是奖励事件。未来持续产出或机关设施另列候选，首原型只实现设施节点。

完成条件：第一次探索的选择至少在一次后续考验中可观察地影响结果；同一房间可在多次考验复用且不会重新领奖；未探索、仅清空、已布防三种状态均能走完流程。用例 R01–R04、E02，见 [07](07_验收与证据.md)。
