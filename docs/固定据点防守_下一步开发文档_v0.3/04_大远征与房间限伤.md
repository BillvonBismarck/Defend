# 大远征与房间限伤

依据 U05。原话没有明确限伤对象或敌人规模。P 首原型采用“一只远征主敌，在每个必经房间有共享累计承伤预算，最后回核心可击杀”；这不是用户最终确认。其他解释见 Q-X1。

## X01 路线和阶段

远征是波次进攻实体的行为类型，不移动核心、不护送玩家。主敌拥有稳定 entity_id、wave_id 和 route_id，所有阶段均纳入本波存活计数。

路线为有序物理路点及房间站点：SPAWNING → TRAVELLING → ROOM_ENGAGED → LEAVING → 下一站 TRAVELLING → FINAL_ASSAULT → DEAD。阶段不表示重新生成敌人。

P 三房间样板经过 A1/B1/C1 再回核心；允许真实折返主殿连接。扩展版按顺序经过地图中全部 challenge_target 房间形成外圈巡行，再回核心。后勤区和普通连接点不是限伤房间。路线不能仅在 UI 上绕圈。

每站配置进入点、交战点、出口点；到达交战点后开始该房间战斗计时。主敌在房间内攻击合法范围中的角色或设施；没有目标仍按计时前进，不以玩家在场或房间已清作为继续条件。

达到该站预算或交战计时结束则进入 LEAVING，沿合法出口离开，不传送下一房间。移动、攻击和状态使用现有模拟时钟，暂停冻结；所有必经站处理完才进入 FINAL_ASSAULT。

## X02 累计限伤

计账键为 run_id + entity_id + route_id + room_id；每轮远征的新实体有新账本。同实体被击退、短暂出界或再次进入同一房间均不重置预算。

只有 ROOM_ENGAGED 阶段接受房间伤害。提交伤害时按目标当前合法站点取预算，不按攻击者所在房间，也不按发射时位置。物理房间与当前站点不符时拒绝伤害并记录原因，避免墙边提前计账。

公共伤害入口计算：

```text
remaining = max(0, room_cap - room_damage_used)
actual = min(requested_damage, remaining, max(0, hp - 1))
hp = hp - actual
room_damage_used = room_damage_used + actual
```

角色弹体、塔、溅射、友伤爆炸、未来持续伤害均共享这个预算。单次溢出只结算实际值，丢弃多余伤害，不转移到下一房间。Hit、战报和统计只累计 actual；actual=0 的拦截用单独限伤事件表达，不假装造成伤害。

按现有稳定事件顺序提交同帧多来源伤害：预算 10，先到 8 再到 8，实际依次 8/2。首个事件已切换 LEAVING 时后续伤害为 0，也不能越过总上限。

P 巡行阶段始终至少保留 1 HP；并通过配置令各房间 cap 总和小于初始生命，给终局留下明确压力。配置公式、初值集中在 [08](08_原型决策与待定事项.md)。FINAL_ASSAULT 移除巡行限伤，剩余生命继承，可由合法伤害击杀。

## X03 转场、控制与结束

P TRAVELLING/LEAVING 是可见的行军护甲阶段，不接受伤害，UI 显示“转场护甲，前往下一站”。不以隐藏免伤补救未定义的通道归属。

控制仍按公共重量、锚定、减速和碰撞规则处理。击退不回退站点索引；计时到达后推进下一站，已消费预算保持。首原型拒绝影响远征主敌的无限定身候选，不通过刷新预算或重生消除控制。

路径堵塞先向当前合法出口/路点重寻路，不能套用普通怪“回出生入口”的回迁逻辑。多次恢复仍无法移动时记录技术错误并停止该样板的模拟，报告 UNDETERMINED；不发胜利、不删怪冒充清波、不把技术错误算正常玩家失败。

FINAL_ASSAULT 沿合法路径攻固定核心，复用公共攻击和碰撞。P 主敌没有额外召唤，普通队列仍提供并行压力；后续军团/召唤另行评审。

到最后房间、耗尽全部预算或进入终局均不代表死亡。只有 HP 合法归零一次才能掉落、安排死亡反应并减少活怪。清波继续等待生成完成、进攻怪为零、有害反应为零，同时间槽失败优先。

## X04 可读性和验收

显示完整预告路线、当前/下一站、交战剩余时间、站点剩余伤害预算、真实 HP、转场护甲和终局解除提示。限伤值变化不得只靠颜色说明；减少特效保留路线、文字、危险范围及阶段信号。

完成条件：玩家能理解沿途投入如何削弱终局；所有必经房间实体经过；预算无越界或重置漏洞；缺乏沿途输出仍能进入更难的终局；全过程不会误清波。用例 X01–X07、C01/C02、E03 见 [07](07_验收与证据.md)。
