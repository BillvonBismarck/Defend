# 原型决策与待定事项

本文件是新增候选参数的单一权威。全部默认值为 P 提案，未获最终设计确认、未实测、未写入游戏配置。后续授权开发原型时可采用并记录，不需要把每项可逆选择都当成人工审批门槛。

## 原型默认方案

| ID | 候选默认 | 理由与复核依据 |
| --- | --- | --- |
| P01 | 保留三种塔/两次基础升级，每塔一个模块；六个模块 | 从现有框架扩展行为差异，先避免多模块堆叠复杂度 |
| P02 | 模块本局解锁、可装多塔，安装免费、更换20资金；服务费不返 | 无消耗品计数负担；更换仍有机会成本，实测资源取舍 |
| P03 | 首次房间领奖随机三选一合法未拥有模块，独立模块随机流 | 保留探索差异；不扰动原波次及战斗随机顺序 |
| P04 | 主殿4槽，样板A1/B1/C1各1槽；存活塔全局最多6座 | 玩家须取舍主殿/外围；后续槽位数量不等于免费设施 |
| P05 | 外围塔仅所属区域有考验目标时输出；主殿塔照常 | 保留守军探索规则，明确设施职责 |
| P06 | reuse_sample为5波测试，第5波增加1只远征主敌，原普通/精英队列保留 | 快速验证闭环；不改legacy_v02基线 |
| P07 | large_map_proto为20波，中段第10波和终局第20波各增加1只远征主敌 | 每次新实体新预算，复用同一张地图；困难度需实战调整 |
| P08 | 完整地图8–12探索/防守房间，三外圈区、至少两处跨区连接、至少一条可解锁回防捷径 | 提供路线选择而非仅扩大空地 |
| P09 | 初始远征HP=1200；N个必经房间每站cap=600/N，浮点统一误差容限 | 全站合计最多削弱50%生命，终局仍有压力；N=3时每站200 |
| P10 | 每站交战窗口12秒；达到预算或窗口耗尽后离场；巡行保留≥1HP | 不因玩家缺席或输出不足无限等待；数值须按真实行程校准 |
| P11 | 转场护甲免伤、无额外召唤；控制仍服从公共规则 | 降低通道预算歧义；护甲必须可读，体验不好可替换策略 |
| P12 | 公开地图轮廓和路线；考验开沿线门但不清房/领奖 | 验证路线与构筑优先；保持未清探索内容 |
| P13 | 新role=expedition，基础移速/半径/近战/范围攻击/重量继承commander；HP覆盖P09，is_boss=true，关闭召唤，视觉复用现有统领并加远征标识 | 避免猜测完整新敌人表；仍需特定阶段行为与Boss分类接入 |

原有价格、角色成长、战备/预警等继续从 legacy 配置派生；本包不维护第二份原值表。

## 六个模块候选参数

先计算原塔基础+升级+角色协同得到有效属性，再应用模块修饰；减速在公共解析器最终做上限及Boss处理。应用一次，不在面板或每帧累加。

| 模块ID | P 修饰 |
| --- | --- |
| rapid_focus | 伤害/间隔不变；射程内优先远征主敌或精英，同优先级按距离、entity_id稳定排序 |
| rapid_sweep | 有效伤害×0.8，额外穿透1目标，保留合法LOS和去重 |
| slow_field | 有效范围+1.5格，减速量-0.10，下限0 |
| slow_anchor | 有效范围-1格，下限1格，减速量+0.10，仍受公共上限 |
| area_cluster | 溅射半径+0.8格，有效伤害×0.75 |
| area_focus | 溅射半径×0.6，有效伤害×1.3 |

slow塔目前升级/协同的实际修饰以Combat实现为准；首原型模块不改变其普通弹体伤害。上述参数只供实现验证，不能直接宣称六个分支已经平衡。

## 仍需明确或实测的问题

| ID | 问题 | 本包默认及替换影响 |
| --- | --- | --- |
| Q-B1 | “复杂构筑”是否还需机关、供能、资源链或自由建造 | 先实施六模块+分区部署；扩展时重新评估阻路、经济与性能 |
| Q-B2 | 模块获取、更换费、存活设施上限是否合适 | P02–P04可调整；保留幂等、成本分离和同预算验证 |
| Q-M1 | 大地图是单关空间还是跨章节世界地图 | P08单关；后者另需关卡选择、进度与持久化契约 |
| Q-M2 | 地图精确形状、房间位置/职责、是否随机生成 | 按02制作有证据的固定灰盒；随机生成不属于默认 |
| Q-R1 | 考验波敌人的类型、数量、固定波点及奖励 | P06/P07；特殊单位死亡奖励初值复用当前统领经验/资金，独立role但唯一结算 |
| Q-X1 | “限伤”是敌人累计承伤、单次伤害、玩家受伤，还是整支军团预算 | 本包采用敌人累计承伤；改变解释需同步04、05及X02/X03/E03 |
| Q-X2 | 远征是一只主敌还是军团，“走一圈”是否要求覆盖每个房间 | 一只主敌覆盖全部challenge_target；非战斗后勤/连接点不分预算 |
| Q-X3 | 转场免伤、驻留窗口、伤害预算、终局保留比例是否自然 | P09–P11；以玩家解释与拦截选择复核，避免无意义等护甲 |
| Q-X4 | 重复访问重置、跨房间伤害、减速/击退、卡路恢复 | 当前04策略保持预算与前进顺序；改动须新增漏洞回归 |
| Q-E1 | 三种策略的实际强度、探索耗时、20波总时长 | 以真实操作测量；原18–22分钟是候选目标，不机械缩时间达标 |
| Q-E2 | 正式目标设备、平台存储和性能阈值 | 实际环境记录；本包不承诺FPS/平台持久化 |

## 记录格式

```text
决策ID / 状态：P临时采用、用户确认、实测修订或Q未决
采用内容与来源：
适用scenario_id / rules_version：
理由与复现证据：
受影响规则、字段、配置、UI和验收ID：
替代旧值及兼容处理：
```

Q 不意味着所有工作停止。按06依赖推进独立任务；原型可采用明确P方案，最终规则变化须有可追踪的决定或实测依据。
