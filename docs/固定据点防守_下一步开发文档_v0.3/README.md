# 固定据点防守：下一步开发文档 v0.3

编制日期：2026-10-06。文档版本：v0.3 提案；游戏当前实现仍以实际源码为准。

本包承接聊天分析的第 2、3、4、5 项：防守构筑、大地图、房间复用与考验波次、大远征与每房间限伤。此次仅生成开发文档，未实施玩法、启动预览或远程构建；原 v0.1/v0.2 文档保留。

目标循环：高效清波获得探索时间 → 选择探索路线 → 获取横向构筑能力 → 配置主殿及外圈防线 → 考验敌人经过既有房间 → 玩家判断沿途拦截或回核。

## 推荐开发请求

```text
读取本目录 AGENTS.md、00 和 06，执行 N00 至 N08 的完整原型开发。
按 08 中 P 候选配置实施，记录采用项；这些配置不升级为用户最终确认。
先保留 v0.2 回归，再完成构筑、房间复用、远征样板和扩展地图。
按 05 维护字段、因果提交与清波身份；按 07 提交规则、运行和体验证据。
遵守项目根的 Maker 流程；本请求不包含远程构建、提交或推送。
缺少运行条件时继续可独立完成的工作，列明 UNDETERMINED/NOT_RUN。
```

以上是可复制的后续请求，文档本身不启动开发。完整目标包含大地图；中间的小地图样板用于降低接入风险，不作为四项全部完成的替代品。
