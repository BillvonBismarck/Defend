# 技能伤害倍率表

> 所有伤害基于 `playerAtk`（玩家基础攻击力）计算，除非特别标注。
>
> `playerAtk = Config.PLAYER.baseAtk(6) × 角色倍率`

---

## 基于玩家攻击力的技能

| 技能ID | 名称 | 伤害倍率 | 等级缩放 | 备注 |
|--------|------|---------|---------|------|
| `grab_smash` | 太极拳 | 6.0 | - | 必定暴击，实际 6.0 × 2.0(暴击) = **12倍** |
| `cat_scratch` | 星爆猫爪 | 2.4 | - | 范围伤害 |
| `grenade` | 手雷 | 2.0 | - | 范围随等级增大，倍率不变 |
| `bean_sprout` | 豆芽陷阱 | 1.5 × level | 每级 +1.5 | - |
| `elephant_stomp` | 大象踩背 | 1.5 | - | 每秒踩踏 1 次 |
| `xmas_tree` | 圣诞树 | 1.0 × level | 每级 +1.0 | 接触伤害；冰弹无伤害，只叠冰冻 |
| `slow_rider` | 慢行者 | 1.0 | - | 旋风每 0.5 秒 1 次，持续 5 秒，共 10 次 |
| `atk_drone_green` | 绿色无人机(碰撞) | 1.0 | - | 碰撞伤害固定 100% |
| `thumb_up` | 点赞弹幕 | 0.6 | - | 继承所有子弹加成（穿透、弹射） |
| `atk_drone` | 攻击无人机 | 0.5 × level | 每级 +0.5 | 毕业后碰撞伤害 50% |
| `leaf_storm` | 霜瑟风暴 | 1/3 (≈0.333) | - | 频率随等级增加：每秒 2×level 次 |
| `atk_drone_green` | 绿色无人机(激光) | 0.25 × level | 每级 +0.25 | 远程激光伤害 |
| `clone_strike` | 分身打击 | 0.2 | - | 猴子专属：散射每级额外 +0.1 |
| `otto_box` | 盒子 | 继承僚机 × 0.5 | - | 复制所有僚机技能，伤害减半 |

## 不基于玩家攻击力的技能/机制

| 技能ID | 名称 | 伤害来源 | 说明 |
|--------|------|---------|------|
| `charm_enemy` | 魅惑敌人 | **被魅惑敌人自身 atk** | `max(1, floor(敌人atk))`，每秒 6 次 |
| `big_bullet` | 巨弹强袭(被动) | 子弹 ×3 + **敌人最大生命 0.2%** | 2% 概率触发；×3 部分基于玩家攻击力，0.2% 部分不基于 |
| 冰弹 | 圣诞树附属 | 无伤害 (`damage = 0`) | 只叠加冰冻层 |

## 全局伤害加成（乘算）

| 加成来源 | 倍率 | 说明 |
|---------|------|------|
| 过载 | ×2.0 | 叠加在 `Player.GetEffectiveAtk()` |
| 狂暴 | ×3.0 | 叠加在 `Player.GetEffectiveAtk()` |
| 暴击 | ×2.0 | 基础暴击伤害倍率 |
