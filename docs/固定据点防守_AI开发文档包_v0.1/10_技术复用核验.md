## E 证据报告格式

每个模块记录实际文件路径、类或函数、观察到的能力、限制、建议复用方式及证据类型。状态可用“已有且运行验证”“存在源码尚未运行”“需修改”“需新增”“输入缺失”。不要把源码存在当成运行通过。

| 证据层次 | 能支持的结论 |
| --- | --- |
| 源码与配置 | 某接口、数据或逻辑存在 |
| 自动测试 | 在测试环境中该规则成立 |
| 编辑器或本地运行 | 当前本地运行行为可复现 |
| 构建 | 目标构建产物生成成功 |
| 目标平台运行 | 在实际平台可启动与操作 |
| 实战与视觉检查 | 回防、性能、可读性和体验目标是否达到 |

不同证据分别报告。没有目标平台验证时保持其未验证状态。软上限 80、生成间隔 0.8 秒和时长均需验证，不能凭策划文本认定性能达标。
