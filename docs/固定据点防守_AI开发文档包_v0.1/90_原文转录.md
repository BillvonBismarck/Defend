## 02 主循环、状态转换与胜负规则

三个嵌套循环

秒级：读进攻方向 → 移动拦截/回防 → 攻击与技能 → 拾取经验和资金 → 升级判定 → 检查进攻怪是否清空。

波次级：15 秒战备/探索 → 8 秒预警 → 敌人按配置进入 → 清波奖励 → 未到终局则进入下一次战备。

章节级：选择角色与方案 → 章节开场 → 固定据点守核 → 终局胜利/失败 → 结算解锁 → 调整方案重试。

| 状态 | 进入时执行 | 离开条件 |
| --- | --- | --- |
| 入场部署 | 核心耐久与角色生命重置；初始化起始技能、60 资金与地图状态。 | 开场结束或跳过后进入首次战备。 |
| 战备 / 探索 | 15 秒真实游戏时间；可布防、修复、清据点。开波按钮允许提前结束。 | 倒计时归零或主动开波；窗口内最后 8 秒显示方向预告。 |
| 开波预警 | 保证累计 8 秒方向提示；提前开波但预告不足时，补足剩余预警时间。 | 预警足够后执行本波生成队列。 |
| 波次进攻 | 推进怪向核心行进；玩家战斗、拾取、升级；允许高风险外圈探索。 | 生成队列执行完成，且当前 wave_id 的存活进攻怪数量为 0。 |
| 升级选择 | 经验达到阈值时暂停世界；显示 3 个合法且不重复选项。 | 选中后恢复原状态；经验溢出可触发下一次选择。 |
| 本波结算 | 奖励只发一次；检查角色/核心存活和是否清空第 20 波。 | 非终局进入下一次战备；终局进入胜利。 |
| 结束结算 | 停止生成、伤害与拾取；保留已结算的局外奖励。 | 重试或返回章节选择。 |

胜负与优先级

胜利：第 20 波生成结束且进攻怪清空，角色生命 > 0、核心耐久 > 0；不是仅击杀 Boss 或撑够时间。

失败：任意局内状态中角色生命 ≤ 0 或核心耐久 ≤ 0。同帧出现失败条件与 Boss 死亡时，先判失败。

外圈守军不计入清波计数；Boss 的召唤物计入当前波。Boss 死亡停止后续召唤，但已生成的召唤物仍须清理。

原型不设付费续命或默认复活；失败清空局内经验等级、技能构筑、防守资金、设施与据点状态。

## 03 操作、成长与资源闭环

操作与战斗：继承方向，待接原项目确认

默认方案为移动控制 + 自动索敌攻击 + 一个主动技能。移动负责选位、躲避、拦截与回防；主动技能用于处理精英、爆发或紧急救核。键鼠/触屏映射随目标平台确定，不在本案中假定必须手动瞄准。

索敌优先可攻击的最近敌人；不穿越不可攻击目标或墙体锁定。实际射程、命中和原技能体系以复用核验为准。

角色与核心使用独立生命/耐久。守核压力不能被角色无敌、离开战区或暂停升级错误地重置。

局内成长

击杀掉落经验；近身拾取产生升级。每次升级从 3 个合法选项选 1 个；方向涵盖单体、范围、控制、生存、机动与防守协同，至少能形成三套不同方案。经验阈值示例：下一级需求 = 20 + 10 × (当前等级 − 1)，只作为首轮体验参数。

同一技能升级依赖前置等级；满级项不再出现。候选不足时，用生命恢复或资金奖励补齐。

选择面板暂停怪物、弹体、伤害、生成队列、战备计时和技能冷却；选择关闭后恢复，防止升级期间核心被偷袭。

第 1 次升级保证有范围或控制选项；第 3 次升级开始出现防守协同。具体权重需试玩调整，不声称原项目已实现。

两种局内资源与一种局外记录

| 资源 | 来源 | 去向 / 重置 |
| --- | --- | --- |
| 经验 | 普通怪 2、精英 10、Boss 30；据点也可提供经验包。 | 用于本局升级；败退或新局清空。 |
| 防守资金 | 起始 60；普通怪 1、精英 8、Boss 30；清波奖励 12。 | 建造/升级设施、修复核心、治疗角色；新局清空。 |
| 据点奖励 | A1/B1/C1 各 40 资金 + 20 经验；二级据点各 80 + 40。 | 每个据点每局只领取一次，不允许反复刷资源。 |
| 局外解锁记录 | 每完成 5 波记录阶段奖励；首次通关解锁下一章节。 | 失败保留已结算记录；不把局内资金兑换成永久数值。 |

战备决策：同一份资金必须取舍

修复：40 资金恢复 200 核心耐久，每局最多 3 次且不超过上限；治疗：20 资金恢复 25 角色生命；建造与设施升级见第 7 节。修复、治疗和建造均仅限战备状态，点击时暂停世界并即时扣款，关闭菜单恢复剩余战备时间。

目标不是让设施替玩家挂机：角色应处理至少一条主要压力路线，设施帮助稳定另一条路线；此为体验验收目标，须通过实战数据确认。

地图组织原则

主殿保持三条可通行入口；外围通过狭窄通道连接资源房。地图底色不是额外自由战场，避免绕开进攻路线无限风筝。

拦截区是推荐站位而非强制任务点。玩家在同一主殿内换位，不构成防守目标迁移。

三路入口到核心的时间差要给出回防机会：最短推进路线约 11 逻辑格，角色示例速度 4.5 格/秒，推进怪 1.2–1.5 格/秒；均为首轮调参目标。

外圈据点状态与奖励

据点状态为：未进入 → 激活守军 → 清空 → 奖励已领取。守军只守房或追逐进入房间的玩家，不主动参加进攻核心的波次；走出房间不重置已造成的伤害，不允许重复领取奖励。二层据点需清空同链一层据点后开启。

时间风险与回城

战备仅 15 秒；方向预警在最后 8 秒开始。深层据点通常不能靠一次窗口完成，玩家可选择放弃探索，或承担战斗期离开主殿的风险。

已清空据点可在战备期使用回城按钮，1.5 秒引导后到后勤区；受击打断；进入波次进攻时回城禁用。未清据点不能回城。

距离核心较远且战备剩余 ≤ 8 秒时，显示醒目的回防提示；核心受击时出现血条闪烁、方位箭头和区别于角色受伤的音效。

生成与清波规则

非 Boss 波预期战斗约 30–40 秒，Boss 波约 45–65 秒；这是体验目标，不强制到时胜利。因构筑与探索变化可更长。

生成队列按入口分配，默认每 0.8 秒生成一批、每入口每批 1–3 只；错峰参数写入波次配置，不依赖角色当前位置刷怪。

建议同屏进攻怪软上限 80：达到上限时延后下一批，不删除敌人、不提前清波。上限须在原项目性能核验后确定。

场外卡住的进攻怪超过 3 秒无路径进展时重寻路；仍无解则迁回同入口的合法点，保留生命与 wave_id，不能默默吞掉敌人。

## 07 敌人职责、核心压力与防守设施

敌人设计：不能所有敌人都只追玩家

| 类型 | 首轮数值建议 | 行为 / 目标 | 应对方式 |
| --- | --- | --- | --- |
| 推进怪 | 生命 20；速度 1.2 格/秒；打核心 5 | 主目标是核心，近距离受阻时攻击角色或设施。 | 范围清理，在入口到核心之间截击。 |
| 远射怪 | 生命 14；速度 1.0；打角色 8 | 优先骚扰进入警戒区的角色；无目标则推进。 | 换位靠近，避免被远射拖住不回防。 |
| 冲锋怪 | 生命 30；速度 1.5；撞核心 15 | 短预警后直线冲刺；障碍会中断冲刺。 | 控制打断，利用拐点截击。 |
| 破阵精英 | 生命 250；打核心 20 | 优先破坏阻挡它的设施，随后进攻核心。 | 单体爆发与控制；提前调位置。 |
| 统领 / Boss | W10/W15/W20 生命 800/1300/2000 | 主目标核心；包含有预警的范围攻击与有限召唤。 | 技能爆发、躲预警、处理召唤物后再清波。 |

角色生命建议 100、核心耐久 1000。伤害与生命仅用于原型建档，未经过平衡测试；不能把以上数值当作原项目已实现能力或最终承诺。

四槽位防守设施

| 设施 | 建造 / 升级价格 | 定位与取舍 |
| --- | --- | --- |
| 速射塔 | 80 / 60 防守资金 | 稳定单体，优先拦截最近推进怪；不负责远处全图输出。 |
| 减速塔 | 90 / 70 | 扩大回防时间窗；对 Boss 使用减弱的控制效果。 |
| 范围塔 | 110 / 80 | 处理密集普通怪；对单体精英效率低。 |

T1–T4 每槽 1 座；建造、升级、拆除仅在战备。每塔最多升 2 次；拆除返还该塔累计支出的 50%，损坏塔不返还。

设施使用独立生命；建议初始 150。攻击间隔、范围、控制强度和升级收益作为配置字段，首轮由试玩确定。

设施与角色之间不能相互卡死；基础建造点避开主路径。不能为防守点引入移动、推车或护送逻辑。

优先级与公平性

推进敌人按核心路径前进，不能因玩家走远就让所有进攻停摆；骚扰敌人允许短时间追玩家。关键攻击至少提供约 0.7 秒可读预警，Boss 范围预警覆盖地面而不盖住核心血条。具体数值须按平台、镜头和原攻击体系调优。

## 08 战斗界面与剧情演出接入

界面必须支持守核判断

常驻：角色生命、核心耐久、当前波/20、战备或预警计时、经验条、防守资金、主动技能状态。核心耐久始终可见，不能只在靠近时出现。

小地图：固定核心、玩家位置、W/E/S 进攻方向、设施、据点状态。未开启波次入口不显示为正在进攻。

警报：核心受击闪烁 + 方位箭头 + 独立音效；低于 30% 耐久使用持续但不过度遮挡的紧急提示。

战备操作：同屏显示剩余时间、资金和价格；缺钱禁用并说明原因。修复次数、满耐久、建造槽占用等限制必须可读。

升级面板：三个候选的效果、当前等级与升级后变化；选择后恢复原波，不重复生成开波奖励。

暂停 / 失焦：单人原型暂停全部模拟；恢复前显示当前波与进攻方向，避免后台核心被打坏。具体接入依平台确定。

剧情暂不写定：先把演出节点接进主循环

| 节点 | 建议时长 / 形式 | 游戏状态与要求 |
| --- | --- | --- |

高质量的执行标准

不是一张立绘平移：至少分前景、人物、背景，搭配镜头运动、表情/关键动作、局部特效与清晰构图。

镜头节奏与配音、音乐、环境/动作音效共同设计；先完成分镜与声音节拍，再制作最终素材。

章节演出支持跳过、回看，重试采用短版；跳过后任务信息、波次状态与镜头位置必须一致。

剧情触发只发生一次；关键停顿期间，战备、生成、伤害、弹体与冷却均冻结。恢复后不丢警报或改变核心位置。

剧情留白项：世界观、核心的叙事身份、角色关系、冲突与章节事件。图中“核心 / 据点 / 统领”均为功能称谓，不是正式设定。

## 10 原型验收与待确认事项

主玩法验收：每个分支都要可复现

| 测试场景 | 预期结果 |
| --- | --- |
| 20 波正常推进 | 每波生成与奖励各执行一次；第 20 波及召唤物清空后才胜利。 |
| 角色死亡 / 核心归零 | 任一条件立即失败；同时击杀 Boss 不覆盖失败结果。 |
| 升级时核心正在受击 | 世界、伤害与计时全部暂停；关闭后接着当前波执行。 |
| 清房但仍有进攻怪 | 据点奖励可发，但不提前清波；两种敌人计数互不污染。 |
| 据点反复进出 | 已领取奖励不重复发；未清据点守军生命不被重置套利。 |
| 三入口与建造连通 | W/E/S 到核心都可寻路；设施、尸体和掉落物不得封路。 |
| 进攻怪达到软上限 | 后续批次延期，不删怪、不误判生成完成、不越过原性能边界。 |
| 外圈探索错过战备 | 波次照常开始；战斗中回城禁用，核心警报可读。 |
| 建造 / 修复 / 拆除 | 扣款与返款只发生一次；修复上限、次数与状态限制正确。 |
| 演出跳过 / 重试 / 回看 | 不会重复发奖励、生成敌人或移动核心；任务与预警完整。 |
| 失败再开新局 | 局内构筑、设施、资金与据点重置；已结算局外记录保留。 |
| 两图与正文对照 | 核心坐标、三个入口、四建造点、20 波和回路完全一致。 |
