# 操作战斗与局内成长

来源：[原文第三节](90_原文转录.md#s03)。本模块均为 P 候选，复用程度按 C03 核验。对应 T03、T05。

## R05 输入和攻击

默认操作为移动 + 自动索敌攻击 + 一个主动技能。移动用于选位、躲避、拦截和回防，主动技能用于精英爆发与紧急救核。键鼠或触屏映射依平台确定；原文没有要求必须手动瞄准。

索敌优先可攻击的最近敌人，墙体与不可攻击目标不能被穿越锁定。实际射程、命中规则、武器和技能体系先核验原项目。角色生命与核心耐久独立；角色无敌、离开战区或升级暂停不会重置核心压力。

Q04 未决：主动技能的具体效果、攻击频率、玩家基础伤害、碰撞模型、控制范围。可以在明确原型任务中临时配置，但需要写入决策记录和配置来源。

## R06 经验和三选一

击杀掉落经验，近身拾取产生升级。据点可奖励经验包；经验包的即时入账或掉落实体形式见 Q12。

| 项目 | P 初值或规则 |
| --- | --- |
| 普通怪经验 | 2 |
| 精英经验 | 10 |
| Boss 经验 | 30 |
| 下级需求 | 20 + 10 × (当前等级 − 1) |
| 每次升级 | 3 个合法且不重复候选，选 1 个 |
| 构筑方向 | 单体、范围、控制、生存、机动、防守协同 |
| 体验目标 | 至少形成三套不同方案 |
| 第 1 次升级 | 保证范围或控制候选 |
| 第 3 次升级起 | 开始出现防守协同 |

同一技能升级依赖前置等级，满级项移出候选池。候选不足以凑齐 3 个时，用生命恢复或资金奖励补齐。补齐项身份、重复限制和金额尚未规定，见 Q12。不得用不存在的技能前置生成非法选项。

经验超过阈值时，选择后再次检查溢出，可连续进入下一次选择。E 建议：通过待处理升级队列或等效机制消费阈值，避免丢经验或重复升级；初始等级及累计经验语义见 Q12。

## R07 成长暂停

面板开启期间冻结怪物、弹体、伤害、生成、战备计时和技能冷却。关闭后回到原状态和当前波次，不发新一轮开波奖励、不重新创建敌人。暂停机制使用 [01 R03](01_主循环与状态机.md#r03-暂停与恢复)。

## 原项目检查清单

- 输入映射是否可替换，移动速度单位如何映射逻辑格。
- 自动索敌是否支持墙体与目标合法性过滤。
- 经验阈值、前置条件、满级过滤与溢出升级是否已有实现。
- 选择界面能否暂停所有模拟子系统，原状态如何恢复。
- 掉落残留、拾取半径和大量实体的运行成本如何验证。

完成证据：V04、V16；三套方案的可用性需实战记录，不能仅凭候选表有六种标签通过。
