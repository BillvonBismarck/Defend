# Dark Tech 令牌表

RGBA 8-bit。两条路线共用同一套值——自绘路线读本地 `C` 表，组件路线由 `UI.Theme.Color(name)` 取（映射见 [`ui-bridge.md`](ui-bridge.md)）。

**不要为「差不多青」再开一色。** 新页面先在这里找。

## 核心色板

### 层级底（越往上越亮）

| Token | RGBA | 用途 |
| --- | --- | --- |
| `bg` | `7, 11, 20, 236` | 全屏底、窗口外层 |
| `panel` | `10, 16, 28, 248` | 窗口外壳、标题栏 |
| `rail` | `12, 20, 34, 255` | 内容区、侧栏、工作区 |
| `card` | `16, 26, 44, 255` | 卡片、未激活控件、选中行底 |
| `widget` | `22, 36, 56, 255` | 输入框、滑轨、次级容器 |
| `cardLit` | `30, 48, 78, 255` | 高亮卡面（选中 / 可交互），比 `card` 再亮一档 |

排序固定：`bg` < `panel` < `rail` < `card` < `widget` < `cardLit`。分层靠明度差，不靠阴影。

### 强调与文字

| Token | RGBA | 用途 |
| --- | --- | --- |
| `cyan` | `0, 229, 208, 255` | 激活、主操作、进度、焦点。唯一主强调色 |
| `cyanDim` | `0, 150, 148, 220` | 弱描边、分隔、滚动 thumb |
| `cyanSoft` | `0, 150, 148, 80` | 激活态底色、极淡填充 |
| `ink` | `4, 8, 16, 255` | **青底上的字**。不要用纯黑 |
| `text` | `240, 248, 252, 255` | 主文字。不要用纯白 |
| `dim` | `120, 148, 162, 255` | 次文字、提示、禁用、占位 |
| `warn` | `255, 196, 72, 255` | 警告、注意 |
| `error` | `232, 93, 91, 255` | 明确错误 |

### 状态派生

需要一个颜色变体时，从基础色派生，不要另开色相：

| 状态 | 做法 |
| --- | --- |
| hover | 基础色 +8~16 明度（深色底）或压暗（浅色底） |
| pressed / active | 基础色压暗约 20%，或换 `cyanSoft` |
| disabled | 换 `widget` 底 + `dim` 字 |

组件路线不需要手做——写进主题的 `*Hover` / `*Pressed` / `disabled` 字段即可。

## 可选注释层

实验室 / 异常感用，**不当主品牌色**。透明度通常 40–150，不能压过正文。

| Token | RGBA | 用途 |
| --- | --- | --- |
| `blue` | `77, 177, 255, 255` | 数值、经验条、信息类 |
| `gold` | `201, 168, 76, 255` | 次级警示、注释十字。比 `warn` 暗，用于非紧急标注 |
| `klein` | `48, 80, 240, 255` | 虚线标注、次级轴 |
| `ghost` | `186, 214, 255, 255` | 残影、回声、异常提示 |

## 氛围色板

氛围层（见 [`atmosphere.md`](atmosphere.md)）专用。**不是主品牌色**，只在异常高位阈值时顶替 `cyan`，或用于残影、幽灵标注。

| Token | RGBA | 用途 |
| --- | --- | --- |
| `wash` | `0, 229, 208, 255` | 异常态主强调色。与 `cyan` 同族但更脏，pulse 高位时顶替它 |
| `washDim` | `0, 90, 88, 255` | 异常态弱描边、分隔 |
| `ghost` | `186, 214, 255, 255` | 残影、回声、幽灵标注（alpha 常压到 40–150） |
| `halftone` | `20, 48, 120, 255` | 网点纹理点色，配合 alpha 14–22 |
| `railMark` | `92, 168, 162, 255` | 侧栏刻度标记 |
| `ash` | `128, 148, 154, 255` | 中性灰，用于非强调的刻度、辅助线 |

规则：

- `wash` / `washDim` 必须和 `cyan` / `cyanDim` **成对定义**，切换时整对替换，不要只换其中一个。
- 残影和幽灵标注**只描边**，且透明度跟随氛围标量（40 + pulse × 70 一类）。
- `halftone` 只用于背景纹理，永远不要用来画文字或边框。

## 结构渐变与表面令牌

本项目的「厚」不靠阴影，靠**成对的渐变端点**。这些值来自 `THEMES` 色板的实际定义，复刻界面时直接取用。

### 渐变端点（成对使用）

| Token | RGBA | 用途 |
| --- | --- | --- |
| `bgTop` / `bgBottom` | `5, 10, 18` / `2, 5, 12` | 全屏背景竖直渐变 |
| `railTop` / `railBottom` | `18, 28, 42` / `6, 12, 20` | 侧栏、槽位、缩进条 |
| `tankTop` / `tankBottom` | `16, 26, 38` / `8, 16, 24` | 舱体壳体 |
| `tankFillTop` / `tankFillBottom` | `4, 20, 36` / `0, 71, 83` | 舱内胆（alpha 180 → 200） |

规则：渐变**只在同一色相族内走明度**，不要跨色相。端点差值控制在 8–20（8-bit）之间，超过就变成「塑料感」。

### 表面与标记

| Token | RGBA | 用途 |
| --- | --- | --- |
| `fluid` | `0, 90, 88` | 舱内液面（alpha 48–84，随氛围浮动） |
| `glow` | `0, 197, 185` | 内发光，比 `cyan` 暗一档 |
| `highlight` | `206, 255, 252` | 玻璃高光条（alpha 18–28，极淡） |
| `dot` | `10, 18, 28` | 铆钉 / 定位点外圈 |
| `readyCard` | `8, 42, 44` | 可升级卡片底（比 `card` 更青） |
| `toastBg` | `8, 22, 28` | 轻提示底 |
| `letterbox` | `5, 10, 18` | 非设计区填充，避免宽屏露黑边 |
| `outline` | `4, 8, 16` | 文字描边色（alpha 230） |

规则：

- `highlight` 只能用在**竖直窄条**上模拟玻璃反光，不要大面积铺。
- `readyCard` / `washDim` 这类「状态底」要和普通 `card` 拉开但**不能亮过一个控件**。
- `letterbox` 必须比 `bg` 略暗或等深，否则宽屏上会看到两种底色接缝。

## 字号

自绘路线直接给 NanoVG 像素值；组件路线的 `fontSize` 是 pt，换算 `pt = px * 0.75`。

| 角色 | 自绘 px | 组件 pt | 设计稿 px | 颜色 |
| --- | --- | --- | --- | --- |
| 窗口主标题 | 15–17 | 11.25–12.75 | 20–23 | `cyan` 或 `text` |
| 区域标题 | 11–13 | 8.25–9.75 | 15–17 | `cyan` |
| 正文 | 11–12 | 8.25–9 | 15–16 | `text` |
| 按钮 / 标签 | 9–11 | 6.75–8.25 | 12–15 | 随状态 |
| 辅助、单位、时间 | 9–10 | 6.75–7.5 | 12–13 | `dim` |
| 编辑中的数值 | 10–12 | 7.5–9 | 13–16 | `cyan` |

组件路线用 `UI.Theme.FontSize(pt)` 取换算后的值，不要自己乘。

## 圆角

小圆角是风格的一部分。**不要药丸（9999），不要直角（0）。**

| Token | 值 | 用途 |
| --- | --- | --- |
| `none` | 0 | 进度条端点、装饰线 |
| `xs` | 3 | 标签、进度条 |
| `sm` | 4 | 输入框、列表行、滑轨 |
| `md` | 6 | 默认控件、卡片、窗口、按钮 |
| `lg` | 8 | 大面板 |
| `xl` | 10 | 浮层 |
| `full` | 11 | 胶囊 Chip（**注意不是 9999**） |

窗口取 4–8，控件取 3–6，是 SKILL.md 设计 DNA 第 4 条的具体化。

## 间距

| Token | 值 | 用途 |
| --- | --- | --- |
| 外边距 | 8–12 | 窗口与内容之间 |
| 内容内边距 | 10–14 | 窗口壳内 |
| 侧栏间距 | 8–12 | 侧栏与主工作区 |
| 卡片间距 | 6–10 | 卡片之间 |
| 控件内边距 | 6–12 | 按钮、输入框内 |
| 竖线宽 | 3–4 | 标题识别竖线 |
| 边框宽 | 1 | 默认描边 |

高度不够时的取舍顺序：**先减装饰和间距 → 再缩小字 → 最后才挤内容**。保留顺序：主标题 → 主内容 → 主操作 → 辅助说明。
