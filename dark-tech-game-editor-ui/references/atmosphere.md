# 氛围层：让界面「死气沉沉地活着」

适用：培养舱、实验室、监控面板、异常日志、任何需要「仪器还开着，但已经没人了」气质的界面。

这是本风格区别于普通深色主题的关键一层。前两份参考（[`ui-bridge.md`](ui-bridge.md) / [`nanovg.md`](nanovg.md)）解决**界面长什么样**；这份解决**界面为什么让人觉得不对劲**。

**先想清楚再加。** 氛围层的成本是全屏重绘路径上多几十次绘制调用，而且一旦叠加就容易过火。默认姿态是：界面先安静地成立，氛围只做低频、低幅度、可复现的扰动。

## 核心机制：单标量氛围驱动

不要给每个元素各写一套 `math.sin(elapsed * ...)`。**整屏共享一个 0..1 的氛围标量**，所有元素都从它派生。这样：

- 一次算完，所有调用点读到同一个值 → 同一帧内所有元素同步「发作」，而不是各闪各的
- 调一处就能整体加浓 / 减弱
- 阈值语义集中，不会出现「A 元素在 0.6 触发、B 元素在 0.62 触发」的错乱

```lua
-- VIEW 里放缓存字段
local VIEW = {
    elapsed = 0.0,
    pulse = 0.0, pulseAt = -1.0,   -- 本帧缓存
}

-- 返回 0..1。同一个 elapsed 只算一次，同帧多次调用零成本。
local function AnomalyPulse()
    if VIEW.pulseAt == VIEW.elapsed then return VIEW.pulse end

    -- 基线：极慢的正弦，保证任何时候都有微弱起伏，不会完全静止
    local pulse = 0.08 + 0.06 * (0.5 + 0.5 * math.sin(VIEW.elapsed * 0.19))

    -- 尖峰：用取模周期造出「偶发抽搐」，而不是平滑呼吸
    local cycle = (VIEW.elapsed * 0.31 + seed * 0.17) % 8.6
    if cycle < 0.16 then pulse = 1.0
    elseif cycle < 0.38 then pulse = 0.62
    elseif cycle < 0.52 then pulse = 0.28
    end

    VIEW.pulse = pulse
    VIEW.pulseAt = VIEW.elapsed
    return pulse
end
```

三个设计点值得留意：

- **基线的 `0.08 + 0.06 * ...` 永远不为 0。** 完全静止的画面像截图，不像「还在运转的仪器」。留一点点底噪，界面才有「活着但没人管」的感觉。
- **尖峰用取模周期，不用随机。** 随机会让每帧不可预测，同一屏元素不同步，看起来像 bug 而不像氛围；取模周期可复现、可调，且天然让所有元素同时发作。
- **`seed` 用当前对象 / 页面索引**（例如 `profile_.equipped`）。换一个标本、换一个页面，抽搐的节奏就不同，避免看久了腻。

### 阈值分带

氛围标量本身不可见，**可见的是各元素在阈值上的分层解锁**。把阈值当作一层层往上叠的「症状」：

| 阈值 | 症状层 | 典型表现 |
| --- | --- | --- |
| 常开 | 基线底噪 | 极慢呼吸的透明度、水面波动、气泡 |
| `> 0.28` | 残影 | 主元素偏移几像素的弱拷贝、扫描带拖尾 |
| `> 0.45` | 幽灵标注 | 多出一个不该存在的标签 / 十字 |
| `> 0.55` | 强调色切换 | 青 → `wash`，主色开始「发红」 |
| `> 0.6` | 边框异变 | 描边、角标换色 |
| `> 0.72` | 文本改写 | 状态词被替换（`STABLE` → `DELAYED`） |
| `> 0.72` | 音频锁定 | 一次性异响 |

阈值**不要等距**。等距会读出机械的「档位感」；0.28 / 0.45 / 0.55 / 0.6 / 0.72 这种疏密不匀的分布，观感更像真的在故障。

### 强调色切换

氛围最有效的一招：**主强调色本身会变**。准备一对「异常强调色」，在高阈值时顶替 `cyan`：

```lua
local accent    = pulse > 0.55 and C.wash    or C.cyan
local accentDim = pulse > 0.55 and C.washDim or C.cyanDim
```

`wash` / `washDim` 的定义见 [`tokens.md`](tokens.md)。在青绿主色板上，`wash` 是同一族但更脏、更红的一档——切换时整屏像「同一套仪器换了一种照明」，而不是换了个主题。

**注意别让切换过于频繁。** 阈值附近来回抖动会造成闪烁。要么让尖峰上升沿足够陡（上面的取模周期天然满足），要么加迟滞（进入 0.55、退出 0.5）。

## 残影与回声

实验室感的第二支柱：**让画面里出现「上一个自己」**。

固定偏移 + 低透明度，重复绘制同一元素：

```lua
if pulse > 0.28 then
    nvgBeginPath(vg)
    nvgCircle(vg, cx + 7, cy - 5, r)          -- 偏移 7,-5
    nvgStrokeColor(vg, RGBA(C.ghost, 40 + math.floor(pulse * 70)))
    nvgStrokeWidth(vg, 1)
    nvgStroke(vg)
end
```

要点：

- **偏移要小且固定**（5–8 px）。大偏移看起来像没对齐的 bug，小偏移才像信号串扰。
- **透明度跟着 pulse 走**，让残影在高阈值时才明显。
- **残影只描边不填充**，避免糊成一团。
- 同一个偏移量在整个项目里保持一致（本项目用 `+7, -5`），形成统一语汇。

配合「回声」叙事（本项目用 `+0.73s` 这个反复出现的延迟数字），残影会从纯装饰变成有含义的视觉母题。

## 文本层的异变

氛围到了高位，**文字本身应该开始不可靠**。两个层次：

**1. 状态词替换（廉价、安全、效果好）**

```lua
Text(pulse > 0.72 and "CONTAINMENT: DELAYED" or "CONTAINMENT: STABLE", ...)
Text(pulse > 0.72 and "LAB / HANDS-0?"      or "LAB / HANDS-01", ...)
```

在 `0.72` 这类高位阈值上换掉状态词，代价接近零，但会让人怀疑「刚才写的是不是这个」。

**2. 字符级乱码事件（独立事件，不要挂在 pulse 上）**

乱码**不要**每帧跟随 pulse 抖动——那会变成噪音。做成**低频、短促、可预期的独立事件**：

| 参数 | 建议 | 理由 |
| --- | --- | --- |
| 持续时间 | 2s | 短到不烦，长到能看清 |
| 间隔 | 40–160s 随机 | 远长于单次时长，保证「偶发」感 |
| 影响范围 | 20–80 个字符 | 太少看不见，太多像崩了 |
| 不足下限时 | 全部乱码 | 短文本（按钮、状态）直接全乱 |
| 字形变化 | 事件内每 0.12s 换一次 | 静态替换像「改过」；跳动像「传输错误」 |

实现要点：

- **采集与锁定分帧。** 触发帧只遍历记录「哪些字可乱」，帧末再锁定选中的字。这样绘制路径上没有额外判断，且选中集合在 2s 内稳定。
- **用原始字符串当 key 存替换表**，而不是存位置。同一段文字（如重复出现的 `LOCK`）会一起乱，视觉上反而更像真的坏了。
- **字符按 UTF-8 切分**，不要按字节替换——按字节会切碎中文，变成真正的乱码方块，失去「可读但错了」的微妙感。
- **可被事件强制触发。** 换主题、切换关键状态时清空冷却并立刻触发一次，把氛围事件和玩家的操作绑起来，会比纯随机更「有反应」。

```lua
-- 换色时立刻触发（本项目：切回主色板时）
local function ApplyTheme(id)
    local switchedBack = id == THEME_MAIN and themeId_ ~= THEME_MAIN
    themeId_ = id
    C = THEMES[id]
    if switchedBack then TextGlitch.TriggerNow() end
end
```

**字形选择**：用**同宽、同字号的「形近字」和符号**（`#%?/\@*+×※`、`囗口回田`、`■□▲`），而不是随机汉字。同宽才能保持排版不跳；形近才能读出「本来应该是别的字」。

## 声音跟随氛围

音频不该独立于视觉。用同一个 pulse 驱动增益，画面和声音就会一起「呼吸」：

```lua
local pulse = AnomalyPulse()
if AUDIO.music then AUDIO.music.gain = 0.22 + pulse * 0.10 end
if AUDIO.amb   then AUDIO.amb.gain   = 0.24 + pulse * 0.22 end
```

**一次性音效要锁定，不要连续触发。** 在阈值上「进入时」响一次，而不是「处于阈值上」时每帧响：

```lua
if pulse > 0.72 then
    if not FX.anomalyOn then
        FX.anomalyOn = true
        FX.anomalyTimer = 0.73          -- 延迟一点再响，制造「滞后」
    end
else
    FX.anomalyOn = false
    FX.anomalyTimer = 0.0
end
if FX.anomalyTimer > 0 then
    FX.anomalyTimer = FX.anomalyTimer - dt
    if FX.anomalyTimer <= 0 then PlayLab(SFX.anomaly, 0.42, 0.72) end
end
```

延迟 0.5–0.8s 再响，会让声音听起来像是「画面的反应」而不是「同时发生的第二件事」，因果感更强。

## 分层绘制顺序

一个「有生命」的主体（培养舱、反应堆、监控窗）按这个顺序叠，从后到前：

```text
1. 容器渐变底         GradientBox          静态
2. 裁剪区             nvgSave + nvgScissor 必须
3. 内部渐变           LinearGradient       静态
4. 微型网格           MicroGrid            alpha 26
5. 网点纹理           Halftone             alpha 22
6. 液面 / 填充        随 elapsed 正弦波动
7. 波纹线             3–4 条，相位错开
8. 气泡               确定性伪随机，不要 math.random
9. 扫描带             ScanBand             + pulse 拖尾
10. 主体轮廓 / 刻度环  常开
11. 残影               pulse > 0.28
12. 幽灵标注           pulse > 0.45
13. 文字层             pulse 阈值换词
```

**裁剪区必须包住 2–12 全部**，否则装饰会溢出容器。每一层都轻，叠起来才厚；任何单层过重都会立刻显得廉价。

气泡用 `math.sin(phase + i * 1.7)` 这类确定性函数分布，**不要用 `math.random`**——每帧随机会让气泡瞬移，看起来像噪点。

## 双色板结构等价

氛围层要和主题切换共存。做法：**两套色板拥有完全相同的 key 集合**，切换时整表替换：

```lua
local THEMES = {
    [THEME_MAIN] = { bg = {...}, cyan = {...}, wash = {...}, --[[ 全部 key ]] },
    [THEME_ALT]  = { bg = {...}, cyan = {...}, wash = {...}, --[[ 同样的 key ]] },
}
local C = THEMES[THEME_MAIN]

local function ApplyTheme(id)
    local theme = THEMES[id]
    if not theme then return end
    themeId_ = id
    C = theme        -- 整表替换，所有闭包立刻看到新色板
end
```

**关键约束：`C` 必须是可重新绑定的 upvalue，所有绘制函数直接读 `C.xxx`。**

```lua
-- 对：函数体内每次现取
local function Draw()
    Box(0, 0, 10, 10, 0, C.cyan)
end

-- 错：模块加载时就把颜色绑死了，切色板不生效
local CYAN = C.cyan
local function Draw()
    Box(0, 0, 10, 10, 0, CYAN)
end
```

这是本风格里最容易踩的坑：**一旦把颜色取成模块级局部变量，双色板切换就静默失效**，而且因为不报错，很难查。同理，`THEMES[id]` 的每套色板都要补全所有 key，缺 key 会在切换后表现为「某个元素突然变透明」而不是报错。

切换时机建议绑在已有的状态变化上（换对象、换关卡、切标签页），而不是随机切换——随机切色会让人以为是 bug。

## 克制实装（默认姿态）

氛围层很好用，但**不是每个界面都该全量上**。游戏内 HUD、战斗界面、任何「玩家正在读数字/做操作」的界面，全量氛围会**干扰可读性与操作**——而且休闲街机调性下，「故障感」过重会显得像 bug。

默认按**克制档**实装：**只上「静态或低频、不进入正文区」的那几层**，把高阈值症状（强调色切换、文本异变）留给需要「仪器感」的独立面板。

| 层 | 克制档 | 全量档 | 说明 |
| --- | --- | --- | --- |
| 基线呼吸（极慢透明度） | ✅ 用 | ✅ | 成本最低，效果最稳 |
| 扫描带 `ScanBand` | ✅ 用（仅装饰区/容器内部） | ✅ | **不要**扫过 HUD 读数与正文 |
| 半调网点 / 微型网格 | ✅ 用（背景/空白区） | ✅ | 静态，最安全 |
| 残影（小偏移描边） | ✅ 用（菜单主视觉、面板图标） | ✅ | 偏移固定 5–8px，只描边 |
| 幽灵标注（引线+十字+标签） | ⚠️ 仅面板装饰位 | ✅ | 不进操作区 |
| 强调色切换（青 → `wash`） | ❌ 关 | ✅ | 会让按钮/状态色跳变，玩家以为出错 |
| 状态文本异变（`STABLE`→`DELAYED`） | ❌ 关 | ✅ | 同上 |
| 字符级乱码事件 | ❌ 关 | ✅ | 只在「异常日志」类界面才有叙事理由 |
| 音频联动 | ❌ 关 | ⚠️ | 游戏内音效有自己的节奏，别被氛围抢拍 |

### 克制档的落地规则

1. **氛围标量照旧只算一次**，全屏共享——克制的是**症状层数**，不是机制。§核心机制那段原样保留。
2. **基线不为 0**：即使克制档，也要留 `0.08 + 0.06*sin(...)` 的底噪，否则界面像截图。
3. **阈值只用到 0.28（残影）这一档**，不要接 0.55/0.72 的强调色与文本层。
4. **装饰一律待在裁剪区内**，且**不进入**：HUD 读数、按钮文字、正文段落、任何命中区。
5. **每帧不用 `math.random`**——扫描带位置、呼吸相位全部用 `elapsed` 的确定性函数。

```lua
-- 克制档：只保留底噪 + 扫描带 + 残影，不接强调色/文本层
local function AnomalyPulse()          -- 同 §核心机制，全屏共享
    if VIEW.pulseAt == VIEW.elapsed then return VIEW.pulse end
    local pulse = 0.08 + 0.06 * (0.5 + 0.5 * math.sin(VIEW.elapsed * 0.19))
    local cycle = (VIEW.elapsed * 0.31) % 8.6
    if cycle < 0.16 then pulse = 1.0
    elseif cycle < 0.38 then pulse = 0.62
    elseif cycle < 0.52 then pulse = 0.28 end
    VIEW.pulse, VIEW.pulseAt = pulse, VIEW.elapsed
    return pulse
end

-- 用到的地方只查「低位阈值」，高位症状整体不实现
if AnomalyPulse() > 0.28 then
    -- 只画残影 / 扫描带拖尾；不切色、不改文案
end
```

> 判据：**这一层会不会出现在玩家要读的东西上？** 会 → 关掉。不会（背景、装饰位、容器内部）→ 可以留。

## 禁止

- 让氛围标量各算各的；同帧元素不同步。
- 用 `math.random` 驱动每帧视觉（气泡、抖动、偏移）。
- 阈值等距分布。
- 乱码跟随 pulse 每帧抖动，而不是做成独立事件。
- 按字节替换 UTF-8 字符。
- 一次性音效在阈值上连续触发。
- 把颜色取成模块级局部变量后仍指望色板切换生效。
- 氛围层压过正文可读性——**文字永远是最后被牺牲的**。

## 验收

- [ ] 全屏共享一个氛围标量，且同帧只计算一次
- [ ] 氛围基线不为 0，界面不会完全静止
- [ ] 至少三层阈值症状，阈值非等距
- [ ] 高阈值时主强调色发生切换，而非只是透明度变化
- [ ] 残影偏移小、固定、只描边
- [ ] 乱码是独立低频事件，不是每帧抖动
- [ ] 一次性音效有锁定与延迟，不会连响
- [ ] 装饰全部在裁剪区内，不溢出容器
- [ ] 每帧视觉不使用 `math.random`
- [ ] 双色板 key 集合一致，`C` 可重新绑定
- [ ] 氛围再强也不影响正文阅读
