## 1. 证据分级：怎么分析参考作品

拿到参考截图后，先做这五步观察，每条结论都打【实测】/【推断】/【项目建议】标签。

### 1.1 量像素周期
把截图放大到 4–8 倍，找重复的最小方块边界。若出现稳定的 4px 周期，可【推断】原作用了低分辨率逻辑画布 + 4× 最近邻显示。这只是方向，不是原工程配置。

### 1.2 统计轮廓色
取图标最外圈，多数像素风格用近黑或深蓝黑（如 #10131F），而非纯黑 #000000。纯黑在深色底上会显得脏、缺乏层次。

### 1.3 统计色块数量
数一张图里出现过的不同颜色。优秀像素图标多数 ≤ 9 种可见色。颜色越多越像插画，不像像素画。

### 1.4 观察高光占比
高光（最亮色）面积通常 < 10% 非透明像素。高光一多，剪影就糊。

### 1.5 观察主体占比
图标主体通常不填满容器，四周保留透明边。留白是槽位边框、稀有度描边和 HP 角标的生存空间。

### 1.6 跨作品分析范式

不要只看一款作品就下结论。正确顺序：

```text
共同骨架（多作共有）→ 差异（各作特色）→ 本项目融合哪一面
```

例：两款参考作共有「低分辨率节奏 + 深轮廓 + 有限色块 + 紧凑图标」；差异在底色与特效强度。本项目可定：信息密度学 A 作，元素光效学 B 作。

**红线**：不得复制角色、Logo、道具造型、具体构图；不得把自拟 HEX 说成原作官方色板。

## 2. 9-slice 与完整成品的区分

这是运行时装载最容易出错的地方，先分清素材属于哪一类。

| 类型 | 特征 | 使用条件 |
| --- | --- | --- |
| **完整成品** | 含端帽、螺栓、斜切边、装饰纹理；整图是一个完整按钮/面板 | 控件尺寸 = 源图尺寸，或整数倍等比最近邻；**禁止**非等比拉伸 |
| **9-slice** | 四边是可用内缩量定义的边框/角，中心区域可平铺延展 | 明确给出四边内缩量后，可切给任意尺寸容器 |

判定方法：把图切成四角、四边、中心九块。如果中心块均匀、四角是独立装饰，那它是 9-slice；如果中心块本身有纹理走向（铭牌文字、能量槽、斜切光影），那它是完整成品，不能切。

### 2.1 常见错误

- **把完整成品当 9-slice 切**：中心铭牌被拉变形。
- **把 9-slice 当完整成品等比放大**：边框随尺寸变粗。
- **切片参数对了但源图尺寸写错**：最隐蔽的一种。

切片内缩量是「从边缘往里多少像素」，源图尺寸是「整张图多少像素」，两个独立参数。若把目标控件尺寸当成源图尺寸去采样，切出的区域整体错位，表现为整图被横向粗暴拉伸，而代码看起来「明明设了九宫格」。

### 2.2 校验建议

对完整成品，从文件名或元数据解析出源图宽高，与控件宽高做硬校验，不等就报错，别让它静默拉伸。

## 3. 常见失败模式与根因

| 症状 | 根因 | 修法 |
| --- | --- | --- |
| 边缘发虚、有灰边 | 加载用了线性过滤；或 alpha 未二值化 | 加载改最近邻；后处理做 alpha 阈值 |
| 放大后有半透明脏边 | alpha 二值化缺失 | 透明图 alpha < 阈值 → 0，否则 → 255 |
| 同系列颜色不统一 | 未做色板量化 | 后处理第 5 步映射到统一色板 |
| 图标有的偏大有的偏小 | 未做包围盒归一 | 后处理第 6 步按目标主体尺寸归一 |
| 缩小后糊成一团 | AI 草案是平滑插值伪像素 | 后处理第 1 步核验，不合格重生成 |
| 按钮横向被拉长 | 完整成品被非等比缩放；或 9-slice 源图尺寸写错 | 见 §2 |
| 发光/状态糊进图标 | 辉光烙进了常驻图 | 辉光独立成特效层 |
| 稀有度靠放大主体表达 | 设计错误 | 稀有度用边框/粒子/特效层，主体尺寸不变 |

## 4. 移植到新项目的替换清单

### 4.1 必须替换（项目专属）

- 色板：整套 HEX（`references/palette-project.json` 的 shared_neutral 与 elements）
- 母版尺寸表：按新项目的槽位尺寸重算
- 参考作品名与风格描述
- 批次划分：按新项目的资产清单分组
- 轮廓色：多数情况沿用近黑，但深色主题可能要换

### 4.2 必须保留（通用方法论）

- 证据分级（实测/推断/项目建议）与标注纪律
- 「AI 原图只是草案」这条铁律与 7 步后处理
- alpha 二值化、色板量化、包围盒归一三个关键步骤
- 整数倍最近邻、禁止非整数缩放、禁止反向缩放
- 完整成品 vs 9-slice 的区分与源图尺寸校验
- 批内一致性锁（尺寸/色板/光照/视角/seed）
- 验收清单与交付前 6 问

### 4.3 参数化速查

| 参数 | 本项目取值 | 换项目怎么定 |
| --- | --- | --- |
| 卡牌图标母版 | 64×64 | 按槽位尺寸选 2 的幂 |
| 主体占比 | 44–52 / 64 | 约 70–80% 画布 |
| 最大可见色 | 9 | 保持 ≤ 9 |
| 高光占比 | ≤ 10% | 保持 |
| alpha 阈值 | 128 | 128–160 |
| 光照方向 | 左上 | 全项目统一即可 |
| seed | 42 + 轮次 | 固定基数 + 轮次 |
